## Findings
- [LOW] [category:A01] [internal/test_audit/detection.go:44] fixable:yes — `os.ReadFile(testFile)` resolves `testFile` relative to the process working directory without confirming the path stays within `projectDir`. Paths are sourced from `TESTER_REPORT.md` (AI-generated), so exploitation requires the tester agent to emit a crafted `- [x] \`../../path\`` entry. Mitigation: call `filepath.Abs` and confirm the resolved path shares `projectDir` as a prefix before reading.
- [LOW] [category:A01] [internal/test_audit/sampler.go:39] fixable:yes — `EnsureHistoryFile` accepts `REPO_MAP_CACHE_DIR` from the environment without validating that the resulting path stays within `projectDir`. A relative value containing `..` (e.g. `../..//tmp`) escapes the project tree; an absolute value (e.g. `/etc/`) causes `os.MkdirAll` + file creation to target a system directory (fails unless root, succeeds if writable). Mitigation: reject absolute values or strip `..` components before joining with `projectDir`.
- [LOW] [category:A03] [internal/test_audit/helpers.go:256-298] fixable:yes — `BuildTestAuditContext` interpolates file paths from `ac.TestFiles`, `ac.SampleFiles`, `ac.ImplFiles`, `ac.OrphanFindings`, and `ac.WeakeningFindings` directly into the prompt string fed to `prompt.Render`. If Tekhton's template engine performs `{{VAR}}` substitution on the rendered body, a file path containing a `{{…}}` token (possible in adversarial repos) could inject unintended template directives. Mitigation: escape or strip `{{`/`}}` sequences from user-controlled path strings before inserting into the context block.
