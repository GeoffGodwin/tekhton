#### Milestone 1.1.1.2: Makefile With VERSION ldflags Injection

Layer the Makefile on top of the working binary from 1.1.1.1. Adds `build`, `test`, and `clean` targets and the `-ldflags "-X"` injection path that overrides the `dev` sentinel with the trimmed contents of repo-root `VERSION`.

Files to create:
- `Makefile`

Files to modify:
- None (no Go source changes; the `Version` variable from 1.1.1.1 is already the ldflags target).

Acceptance criteria:
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton` (bare invocation, built via `make build`) prints the trimmed contents of repo-root `VERSION` and exits 0.
- Direct `go build ./cmd/tekhton` (without make, from 1.1.1.1) still produces a binary whose output is the `dev` sentinel — i.e. the Makefile change does not regress the plain-build path.
- `make test` exits 0 (Go's "no tests to run" / "no test files" output is acceptable).
- `make clean` removes the `bin/` directory.
- Makefile sets `CGO_ENABLED=0` for the build target.
- Makefile contains no `build-all` target (cross-compile is deferred to 1.2).
- No `go.sum` is created.

Watch For:
- Use `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION | tr -d '[:space:]')"`. The `tr -d '[:space:]'` is required — a trailing newline in `VERSION` would otherwise embed inside the linker-injected string and break exact-match assertions.
- Do NOT use `//go:embed` for `VERSION` — `embed` cannot traverse out of the source directory (`cmd/tekhton/` → repo root) and would force restructuring.
- Recipe lines must use tabs, not spaces. Makefile indentation errors surface as `missing separator` only at invocation time.
- Ensure `make clean` uses `rm -rf bin/` (or `rm -rf bin`), not a glob that could match unintended paths.
- `CGO_ENABLED=0` must be exported on the build line itself (`CGO_ENABLED=0 go build ...`), not just declared at the top of the file, so it applies only to the build target.

Seeds Forward:
- Milestone 1.1.2 replaces the plain `main` from 1.1.1.1 with a Cobra root command, introduces `go.sum` and `.gitignore`, and adds `--version`/`--help` semantics — the Makefile target structure established here is the surface Cobra will be built against.
- Milestone 1.2 extends this Makefile with a `build-all` cross-compile target; keep the `build` recipe factored so a matrix can be added without rewriting it.
