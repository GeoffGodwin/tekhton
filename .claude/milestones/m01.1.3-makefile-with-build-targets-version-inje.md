#### Milestone 1.1.3: Makefile with Build Targets & Version Injection

Add the Makefile that drives the canonical build, injects the trimmed `VERSION` file contents via `-ldflags`, and provides the `test` and `clean` targets. After this sub-milestone, `make build` is the recommended build path.

Files to create:
- `Makefile`

Files to modify:
- (none)

Acceptance criteria:
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton --version` (built via `make build`) prints the trimmed contents of repo-root `VERSION`.
- Direct `go build -o bin/tekhton ./cmd/tekhton` (without make) leaves `Version` at the `dev` sentinel.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes the `bin/` directory.
- Makefile sets `CGO_ENABLED=0` for the `build` target.
- Makefile contains only `build`, `test`, and `clean` targets (no `build-all` — that is 1.2's scope).
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(VERSION)"` — the symbol path must match the package import path from 1.1.1 exactly.
- Read VERSION with `$(shell cat VERSION)` and trim with `tr -d '[:space:]'` or `$(strip ...)` — leaving a trailing newline breaks the `--version` output match.
- CGO must stay disabled (`CGO_ENABLED=0`) for the static-binary promise required by later self-host milestones.
- Use tab indentation in recipe lines (Make requirement), not spaces.

Seeds Forward:
- Milestone 1.2 depends on the Makefile target structure to add the `build-all` cross-compile target alongside `build`.
- Milestone 1.3 depends on `bin/tekhton --version` printing the trimmed VERSION contents for the self-host assertion.
