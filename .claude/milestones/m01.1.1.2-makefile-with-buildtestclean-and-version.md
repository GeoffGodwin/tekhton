#### Milestone 1.1.1.2: Makefile with build/test/clean and VERSION ldflags Injection

Add the `Makefile` that wires `-ldflags "-X"` injection of the trimmed `VERSION` file contents into the `internal/version.Version` package variable, plus standard `test` and `clean` targets. This sub-milestone validates the full build path that 1.1.2 (Cobra) and 1.2 (cross-compile) will extend.

Files to create:
- `Makefile` (with `build`, `test`, `clean` targets — no `build-all`)

Acceptance criteria:
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton` (bare invocation) prints the trimmed contents of repo-root `VERSION` and exits 0.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes `bin/`.
- Makefile sets `CGO_ENABLED=0` for the `build` target.
- Makefile uses `$(shell cat VERSION | tr -d '[:space:]')` (or equivalent whitespace-stripping form) inside the `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=…"` expression.
- Direct `go build ./cmd/tekhton` (without make) still produces a binary that prints the `dev` sentinel — i.e., 1.1.1.1 behavior is preserved.
- No `build-all` target is present (reserved for 1.2).
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Version comes from `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION | tr -d '[:space:]')"`, NOT `//go:embed`.
- Quote the ldflags value carefully in the Makefile recipe — unquoted whitespace or a trailing newline in `VERSION` will break the injection or produce a binary whose output has a stray `\n`.
- Belt-and-suspenders: trim at print time in `main.go` as well, so a future contributor who hand-edits `VERSION` doesn't ship a binary with trailing whitespace in `--version` output.
- Keep the Makefile minimal — `build-all` cross-compile is explicitly out of scope and lands in 1.2.

Seeds Forward:
- Milestone 1.1.2 replaces the plain `main` with a Cobra root command and adds `go.sum`, `.gitignore`, and `--version`/`--help` semantics on top of this known-good build path.
- Milestone 1.2 extends this Makefile structure with the `build-all` cross-compile target.
