#### Milestone 1.1.1: Go Module & Cobra Root Skeleton

Stand up the Go module with a Cobra root command that builds and runs. Produces a buildable `bin/tekhton` binary responding to `--help`, but no version flag wiring yet.

Files to create:
- `go.mod`
- `go.sum`
- `cmd/tekhton/main.go`
- `Makefile` (with `build` target only)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23` pinned exactly.
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton --help` produces standard Cobra output.
- Bare `bin/tekhton` invocation exits non-zero with help.
- `.gitignore` excludes `bin/` and `*.test`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Pin `go 1.23` exactly in `go.mod` — drift causes CI flake later.
- CGO must stay disabled in the Makefile (`CGO_ENABLED=0`) — required for the static-binary promise.
- Use only `cobra` (not `cobra-cli`) so `go.sum` stays minimal.
- Do NOT add `--version` flag yet — that lands in 1.1.2 with the version package.

Seeds Forward:
- Milestone 1.1.2 depends on `cmd/tekhton/main.go` exposing a hook point for `--version` (e.g., the root command instance must be accessible to wire `Version` field).
- Milestone 1.1.2 will extend the Makefile with `test`, `clean`, and `-ldflags "-X"` injection.
