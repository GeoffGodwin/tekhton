#### Milestone 1.1: Go Module Bootstrap and Cobra Root

Establish the Go module foundation with `go.mod`, the Cobra root command, version injection via ldflags, and the local Makefile build targets. End state: `make build` produces `bin/tekhton` and `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`. No CI, no self-host harness yet.

Files to create:
- `go.mod`
- `go.sum`
- `cmd/tekhton/main.go`
- `internal/version/version.go`
- `Makefile`
- `.gitignore` (modify)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` and pins `go 1.23`.
- `cmd/tekhton/main.go` defines a Cobra root command with no subcommands; `--version` prints the version; `--help` prints standard Cobra help; unknown invocations print help and exit non-zero.
- `internal/version/version.go` exposes `Version` (default `"dev"`) and `String()` which trims whitespace.
- `Makefile` exposes `build`, `test`, `clean` targets. `make build` runs `go build -trimpath -ldflags="-s -w -X main.version=$(cat VERSION)" -o bin/tekhton ./cmd/tekhton`.
- `make build` on a clean checkout produces `bin/tekhton`; `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `go vet ./...` is clean.
- `.gitignore` excludes `bin/` and `*.test`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- `bash tests/run_tests.sh` produces identical output before and after.

Watch For:
- Version injection must be via `-ldflags "-X"`, NOT `//go:embed` (embed paths cannot traverse out of the source directory).
- Direct `go build` without make leaves `Version` at the `dev` sentinel — this is intentional.
- Only depend on `cobra` — no other third-party deps yet.
- The version string must be trimmed of trailing whitespace at print time.
