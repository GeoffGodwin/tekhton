#### Milestone 1.1.1: Go Module Skeleton + Makefile
Stand up the Go module with a minimal `main.go` that builds via `make`. No Cobra, no version injection yet — just prove the module layout, Makefile, and `.gitignore` are correct and the binary builds end-to-end.

Files to create:
- `go.mod`
- `go.sum` (empty / no deps yet)
- `cmd/tekhton/main.go` (minimal `package main` with `func main() { fmt.Println("tekhton") }`)
- `Makefile` (with `build`, `test`, `clean` targets — no ldflags yet, no `build-all`)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23` (exact pin).
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton` runs without error and prints something to stdout.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes `bin/`.
- `.gitignore` contains `bin/` and `*.test` entries.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- No file under `internal/` is created yet.

Watch For:
- CGO must be disabled in the Makefile (`CGO_ENABLED=0`) from the start — required for the static-binary promise.
- Pin `go 1.23` exactly in `go.mod`; drift causes CI flake later.
- Do not add Cobra dependency yet — keep `go.sum` empty.

Seeds Forward:
- Milestone 1.1.2 depends on the Makefile's `build` target structure to add `-ldflags "-X"` injection.
- Milestone 1.1.3 depends on `cmd/tekhton/main.go` existing as the entry point to refactor into Cobra.
