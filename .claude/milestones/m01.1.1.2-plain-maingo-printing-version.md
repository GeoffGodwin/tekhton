#### Milestone 1.1.1.2: Plain main.go Printing Version

Add a dependency-free `cmd/tekhton/main.go` that imports the version package from 1.1.1.1 and prints `version.Version` to stdout, exiting 0. No Cobra, no flags — just `fmt.Println` so direct `go build ./cmd/tekhton` produces a working binary that emits the `dev` sentinel.

Files to create:
- `cmd/tekhton/main.go`

Acceptance criteria:
- `cmd/tekhton/main.go` declares `package main` and defines `func main()`.
- `main()` calls `fmt.Println(version.Version)` (or equivalent that emits the value plus a single trailing newline) and returns normally.
- Only standard-library imports plus `github.com/geoffgodwin/tekhton/internal/version` are used.
- `go build -o /tmp/tekhton-test ./cmd/tekhton` succeeds and produces a binary; `/tmp/tekhton-test` prints `dev\n` and exits 0.
- `go vet ./...` exits 0.
- No `go.sum` file appears after build (no third-party deps).
- Makefile is not yet created in this sub-milestone.

Watch For:
- Do NOT add Cobra, pflag, or any third-party import — that is explicitly milestone 1.1.2's job, and pulling it in here forces `go.sum` to exist prematurely.
- Use `fmt.Println`, not `fmt.Printf("%s", ...)` without a newline — tests in later milestones expect the trailing `\n`.
- Do not call `os.Exit(0)` explicitly; let `main` return so deferred functions added later still run.
- Keep the file under ~15 lines; resist adding logging, flag parsing, or stderr branches.

Seeds Forward:
- Milestone 1.1.1.3 wraps `go build ./cmd/tekhton` in a Makefile target and injects the real version via `-ldflags "-X"`.
- Milestone 1.1.2 replaces this plain `main` body with a Cobra root command while preserving the same stdout-then-exit-0 contract.
