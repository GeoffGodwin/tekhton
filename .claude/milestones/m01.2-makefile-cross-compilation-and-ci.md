#### Milestone 01.2: Makefile, Cross-Compilation, and CI

Wrap the Go build from 01.1 in a `Makefile` with cross-platform targets, then add the GitHub Actions workflow that builds, vets, tests, and lints. Produces five OS/arch binaries as CI artifacts. CGO disabled everywhere.

Files to create:
- `Makefile` (`build`, `test`, `build-all`, `clean` targets)
- `.github/workflows/go-build.yml` (build job, vet+test job, golangci-lint job)

Acceptance criteria:
- `make build` produces `bin/tekhton` with the version correctly injected from `VERSION` (matches `bin/tekhton --version` output, trimmed).
- `make build-all` produces all five binaries: `bin/tekhton-linux-amd64`, `bin/tekhton-linux-arm64`, `bin/tekhton-darwin-amd64`, `bin/tekhton-darwin-arm64`, `bin/tekhton-windows-amd64.exe`. `file bin/tekhton-*` confirms each target shape.
- `make test` exits 0 (Go's "no test files" output is acceptable at this stage).
- `make clean` removes `bin/` cleanly.
- `.github/workflows/go-build.yml` triggers on PR + push to `main` and `feature/GoWedges`, with three green jobs (build-all uploading artifacts, vet+test, golangci-lint advanced preset against `./...`).
- `actions/setup-go` reads `go-version-file: go.mod` (no hardcoded version drift).
- CGO is disabled in all build invocations (verify with `CGO_ENABLED=0` in Makefile and workflow).
- The bash test suite (`tests/run_tests.sh`) is NOT invoked by this workflow.

Watch For:
- CGO must stay off for `darwin/*` cross-compile from Linux to work — any future cgo dep (e.g. `mattn/go-sqlite3`) breaks this.
- Use `-trimpath -ldflags="-s -w"` for release-shaped binaries; combine with the version ldflag without overwriting it.
- `golangci-lint` "advanced" preset on an empty codebase should still be green — make sure no enabled linter trips on the Cobra boilerplate from 01.1.
- The build job runs on `ubuntu-latest` only; cross-compile targets are validated by `file` shape check, not by spinning up matching runners.

- Milestone 04 (later) will add the 80% coverage gate to the test job; 01.2 deliberately ships no coverage gate.
