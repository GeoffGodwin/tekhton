#### Milestone 1.1: Go Module + Cobra Root
Bootstrap the Go module in-repo with a stub Cobra root command and version package. Establishes the package layout (`cmd/tekhton/`, `internal/version/`) that all subsequent Go wedges will build on, without yet wiring any build automation or CI. After this sub-milestone the module compiles via `go build ./...` directly, but no `make` targets or CI exist yet.

Files to create:
- `go.mod` (module path `github.com/geoffgodwin/tekhton`, `go 1.23`, cobra dependency)
- `go.sum`
- `cmd/tekhton/main.go` (Cobra root, no subcommands, `--version` flag)
- `internal/version/version.go` (`Version` var defaulting to `"dev"`, `String()` trims whitespace)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go build -o /tmp/tekhton ./cmd/tekhton` succeeds on a clean checkout.
- `/tmp/tekhton --version` prints `dev` (the unconfigured sentinel).
- `/tmp/tekhton --help` produces standard Cobra help output.
- `/tmp/tekhton somethingunknown` exits non-zero and prints help.
- `go vet ./...` clean.
- `go.sum` is checked in and matches `go.mod`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- `bash tests/run_tests.sh` output is byte-identical to pre-milestone baseline.

Watch For:
- Pin `go 1.23` exactly — drift between local and CI causes flakes downstream in 1.2.
- Keep CGO off — do not add deps that require it (no `mattn/go-sqlite3`); the static-binary promise must hold from day one.
- `internal/version/version.go` must use `var Version = "dev"` (lowercase package-private write via ldflags works because the linker injects on the symbol regardless of export). Use `-X github.com/geoffgodwin/tekhton/internal/version.Version=...` form when 1.2 wires the Makefile.
- Do NOT add `tekhton causal`, `tekhton supervise`, or any other subcommand here — the root is intentionally bare.

Seeds Forward:
- Milestone 1.2 wires the Makefile ldflags that populate `internal/version.Version` from repo-root `VERSION`.
- Milestone 1.3's self-host check asserts `tekhton --version` equals `VERSION`, which only passes after 1.2 lands the ldflags injection.
- m02's `internal/causal/` package will mirror the `internal/version/` layout established here.
