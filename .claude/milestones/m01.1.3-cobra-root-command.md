#### Milestone 1.1.3: Cobra Root Command
Replace the bare `main` with a Cobra root command exposing `--version` and `--help`. Bare invocation exits non-zero with help output.

Files to modify:
- `cmd/tekhton/main.go` (refactor into Cobra root command)
- `go.mod` (add `github.com/spf13/cobra` dependency)
- `go.sum` (populated by `go mod tidy`)

Acceptance criteria:
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION` (via Cobra's version mechanism wired to `version.Version`).
- `bin/tekhton --help` produces standard Cobra help output (usage, flags, etc.).
- Bare `bin/tekhton` invocation exits non-zero and prints help.
- `make build` still succeeds with ldflags injection intact.
- `make test` still exits 0.
- Direct `go build` (without make) still leaves `Version` at `dev`, and `bin/tekhton --version` prints `dev`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Use `rootCmd.Version = version.Version` (or equivalent) so `--version` reuses the same injected string — do not duplicate the lookup.
- Configure the root command so bare invocation returns a non-zero exit code (e.g., `RunE` returning an error, or `SilenceUsage: false` + no default action).
- Run `go mod tidy` to populate `go.sum` deterministically; do not hand-edit it.
- Keep the package layout flat — no `cmd/tekhton/cmd/` subpackage needed for a single root command.
