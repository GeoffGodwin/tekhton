## Design

### Goal 1 — `RunStage` flow

```go
// internal/stages/tester/tester.go
package tester

import (
    inner "github.com/geoffgodwin/tekhton/internal/tester"
    "github.com/geoffgodwin/tekhton/internal/tester/tdd"
    "github.com/geoffgodwin/tekhton/internal/test_audit"
    "github.com/geoffgodwin/tekhton/internal/test_baseline"
)

func RunStage(ctx context.Context, req *stagerunner.Request) (*stagerunner.Result, error) {
    stageStart := time.Now()

    // 1. TDD pre-flight branch (M38.2).
    if req.TesterMode == "write_failing" {
        tddRes, err := tdd.Run(ctx, req)
        if err != nil { return nil, err }  // UPSTREAM error from TDD halts pipeline
        return wrapTDDResult(tddRes, stageStart), nil
    }

    // 2. Build context (architecture, repo map, baseline summary, UI guidance).
    if err := buildTesterContext(ctx, req); err != nil { return nil, err }

    // 3. Render tester prompt (fresh vs resume).
    prompt, err := renderTesterPrompt(ctx, req)
    if err != nil { return nil, err }

    // 4. Invoke primary tester agent.
    agentResult, err := req.AgentRunner.Invoke(ctx, &runner.InvokeRequest{
        Name:     "Tester",
        Model:    cmp.Or(req.TesterModel, "claude-sonnet-4-6"),
        MaxTurns: req.TesterMaxTurns(),
        Prompt:   prompt,
        Tools:    req.AgentToolsTester,
    })
    if err != nil { return nil, err }

    // 5. UPSTREAM short-circuit — write state, SkipFinalChecks, return nil error.
    //    (Different from TDD UPSTREAM which returns non-nil error.)
    if agentResult.ErrorCategory == "UPSTREAM" {
        state.Write(req, upstreamStateEntry(req, agentResult))
        req.SkipFinalChecks = true
        return wrapUpstreamResult(agentResult, stageStart), nil
    }

    // 6. Null-run short-circuit.
    if runner.WasNullRun(agentResult) {
        state.Write(req, nullRunStateEntry(req, agentResult))
        req.SkipFinalChecks = true
        return wrapNullRunResult(agentResult, stageStart), nil
    }

    // 7. Parse self-reported timing (M38.1).
    timing := inner.ParseTesterTiming(req.TesterReportFile, inner.ParseModeReplace)

    // 8. Validate output → routing decision (M38.1).
    decision := inner.ValidateOutput(ctx, req, agentResult)

    var (
        fixResult     *inner.FixResult
        contResult    *inner.ContinuationResult
        auditResult   *test_audit.AuditResult
    )

    switch decision.Routing {
    case inner.RoutingCompilationErrors:
        // Reset checkboxes for compilation-failed files — already done by ValidateOutput.
        // No agent call; operator resumes manually.

    case inner.RoutingTestFailures:
        if req.TesterFixEnabled && req.TesterFixMaxDepth > 0 {
            fixResult, _ = inner.RunInlineFix(ctx, req)  // M38.3
        }

    case inner.RoutingPartialRun:
        contResult, _ = inner.RunContinuations(ctx, req)  // M38.3
        if contResult.Continued {
            auditResult, _ = test_audit.Run(ctx, req)     // M38.4 (audit runs on clean continuation)
        }

    case inner.RoutingClean:
        auditResult, _ = test_audit.Run(ctx, req)         // M38.4

    case inner.RoutingNoReportButTestsCreated:
        // Synthesized report; commit gate tripped — already done by ValidateOutput.

    case inner.RoutingNoReportNoTests:
        // Warn and write state — caller resumes.
        state.Write(req, noReportStateEntry(req))
    }

    // 9. Compute writing time + finalize result envelope.
    timing.WritingS = inner.ComputeWritingTime(int(time.Since(stageStart).Seconds()), timing)
    return finalizeResult(req, agentResult, timing, decision, fixResult, contResult, auditResult, stageStart), nil
}
```

### Goal 2 — Context building

`buildTesterContext` ports the bulk of `tester.sh:65-153`:

- Set MILESTONE_BLOCK via `internal/milestones.SetFocusedMilestoneBlock`.
- Resolve `ARCHITECTURE_CONTENT` via `internal/context.GetCachedArchitectureContent`.
- Build repo map slice for tester (changed files + inferred test counterparts) via `internal/indexer`.
- Call `internal/context.BuildContextPacket("tester", req.Task, model)`.
- Set UI guidance: framework conditional flags (PLAYWRIGHT/CYPRESS/SELENIUM/PUPPETEER/TESTING_LIBRARY/DETOX/GENERIC), optional legacy fallback render of `tester_ui_guidance` prompt when no platform-adapter patterns.
- Build `TEST_BASELINE_SUMMARY` via `internal/test_baseline.Has` + reading the baseline JSON.
- Call `internal/context.AddContextComponent` for "Architecture" and "Repo Map".
- Call `internal/context.LogContextReport`.

All the helpers already exist in Go (M22, M30, M33-adjacent). M38.6 is wiring, not new functionality.

### Goal 4 — Parity tests with recorded fixtures

`internal/stages/tester/testdata/` holds recorded inputs + expected outputs for each routing branch:

| Fixture | Branch exercised | Expected Result |
|---------|------------------|-----------------|
| `clean-pass/` | RoutingClean | Audit ran, Verdict=PASS |
| `partial-run/` | RoutingPartialRun | Continuation ran, REMAINING=0 after |
| `compilation-errors/` | RoutingCompilationErrors | Checkboxes flipped, no agent re-call |
| `test-failures-fix-enabled/` | RoutingTestFailures + FixEnabled | RunInlineFix called, AttemptCount=1 |
| `test-failures-fix-disabled/` | RoutingTestFailures + FixDisabled | RunInlineFix NOT called, error reported |
| `tdd-write-failing/` | TDD branch | tdd.Run called, no main flow |
| `tdd-upstream-error/` | TDD UPSTREAM | tdd.Run returns non-nil error, RunStage propagates |
| `upstream-error/` | UPSTREAM on main agent | nil error returned, SkipFinalChecks=true |
| `null-run/` | Null-run on main agent | nil error returned, SkipFinalChecks=true |
| `no-report-but-tests/` | RoutingNoReportButTestsCreated | commit gate tripped, synthesized report |

Each fixture has:
- `TESTER_REPORT.md` (input — for ValidateOutput)
- `LOG_FILE.txt` (input — for compilation-error / failure-line detection)
- `fake-agent-result.json` (input — for the fake agent runner)
- `expected-result.json` (oracle)

A single table-driven test runs all 10 fixtures.

### Goal 6 — `StageDef` wiring decision: leave `Script` and `Helpers`, or clear?

Two options:

**Option A — Clear `Script` and `Helpers`, set only `GoImpl`.** Cleanest. Once the Go path is dispatched, the bash adapter never runs for tester. Matches the post-port shape of M34-M37.

**Option B — Leave `Script` and `Helpers` populated but null, so bash callers can still source.** Avoids breaking any out-of-tree bash that sources `stages/tester.sh`. But the file is deleted, so this is moot.

Choose Option A. The M34-M37 milestones used Option A and there were no fallout reports.

```go
// internal/stagerunner/helpers.go (modified)
var DefaultStageDefs = map[string]StageDef{
    // ...
    proto.StageTester: {
        GoImpl: tester.RunStage,
        // Script: "", Helpers: nil — fully Go-native after m38.6.
    },
    // ...
}
```

## Watch For

- **Test-failure routing requires BOTH `TesterFixEnabled=true` AND `TesterFixMaxDepth > 0`.** Either alone is insufficient — `TesterFixMaxDepth=0` disables the loop even with TesterFixEnabled=true. Match the bash gate at `tester_validation.sh:76-77`. The `test-failures-fix-disabled/` fixture asserts the negative.
- **MAIN tester UPSTREAM is recoverable (nil error). TDD UPSTREAM is fatal (non-nil error).** This is the same semantic difference flagged in M38.2 and M38.3. The main tester is mid-pipeline — the operator can resume. TDD is pre-flight — the rest of the pipeline depends on it.
- **Compilation-error branch is no-agent-call.** When the log shows compilation failures, ValidateOutput flips the affected report checkboxes back to `[ ]` and the stage exits warn-only. No fix-agent, no continuation, no audit. This is bash semantics at `tester_validation.sh:56-73`. A test that asserts no agent re-call after compilation-error routing guards this.
- **`run_stage_tester` deletes, but `RunStage` is the replacement name.** The bash entry point was `run_stage_tester` (lowercase + underscore). The Go entry point is `tester.RunStage` (PascalCase + package-prefix). All callers (just one, in `stagerunner`) update accordingly.
- **`pipeline_order.sh` still sets `TesterMode`.** M38 does NOT port pipeline_order. The flow is: `pipeline_order.sh` examines `PIPELINE_ORDER` config, sets the `TESTER_MODE` env var on the stage runner request, RunStage reads `req.TesterMode`, dispatches to `tdd.Run` if it's `write_failing`. The `req.TesterMode` value flows from the bash setting through the stagerunner request envelope.
- **`stages/` is NOT empty after M38.6.** Coder family + architect + init_synthesize + plan_* remain. M39 (final stage port) cleans coder. Architect / init_synthesize / plan_* may live longer — they're less hot than the main four stages.
- **`tekhton-legacy.sh` still has the `--start-at` resume routing for tester.** It tests `START_AT=tester` and calls `run_stage_tester`. After M38.6, that bash function doesn't exist — the call routes through the Go binary. Update `tekhton-legacy.sh` accordingly (replace `run_stage_tester` invocation with an exec or rely on the stagerunner dispatch). This is a small change; verify it.
- **The parity-test fixture format is the contract for future stage ports.** M39 will use the same fixture-replay pattern. Make the fixture directory layout reusable: a fake agent runner that reads `fake-agent-result.json`, a fake state writer, a fake gates package. Build these as testing infrastructure inside `internal/stagerunner/stagertest` (or similar) so M39 inherits.
- **VERSION bump is per-decimal, not per-parent.** M38 is `split` status; only the decimal closures bump VERSION. M38.6 is the last decimal, so its bump is the closeout bump.
- **Patch bumps will accumulate during the M38.6 run.** Dogfooded ports of this scale produce 10-20 patch bumps. Don't fight it — every bump fixes a real bug. Track them in `docs/go-migration.md` with one-line postmortems.
