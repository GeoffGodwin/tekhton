# m35.2 — Security Stage Port

## Overview

| Item | Detail |
|------|--------|
| **Arc motivation** | Second child porting the security subsystem (m35 parent). Where m35.1 landed the Go-native helpers behind a bash shim, m35.2 lands the Go-native stage that calls them in-process — and deletes the bash stage entirely. The M34 stage-port pattern is the template: `internal/stages/security/run.go` implements `RunStage(ctx, req proto.StageRequestV1) (proto.StageResultV1, error)`, gets registered in `DefaultStageDefs[proto.StageSecurity].GoImpl`, and the `stagerunner.GoAdapter` dispatches it without sourcing any bash. The 5-subprocess-spawn-per-cycle transition tax from m35.1 retires too — the Go stage calls Go helpers in-process. |
| **Gap** | At m35.1 close, the Go helpers exist and are tested but are reached only via the bash shim from the still-bash stage. The stage logic itself — the scan/rework loop, the agent invocations, the prompt rendering, the env-export emission, the build-gate call between rework cycles, the verdict computation — is bash. ## Design

### Sequencing note

m35.2 has two deliverables that must not be reordered:

1. **Land the Go stage first.** `internal/stages/security/` lands with the `RunStage` entry point, tests pass against fake-supervisor fixtures, the `DefaultStageDefs` rewire is in place. At this point both the bash stage and the Go stage exist — but `GoImpl` is set, so the `GoAdapter` takes the dispatch.
2. **Delete the bash files after the Go path is dogfooded.** `stages/security.sh` + `lib/security_helpers.sh` delete in a follow-up commit once the dogfood run completes without falling back to bash.

Deleting before the Go path is dogfooded means a regression has no fallback. Dogfooding the Go path while bash files still exist gives a one-commit revert path if the Go stage misbehaves.

### Goal 1 — `internal/stages/security/run.go`

```go
// Package security implements the Tekhton security stage (M34 stage-port pattern).
//
// RunStage is the entry point registered in
// internal/stagerunner.DefaultStageDefs[proto.StageSecurity].GoImpl. It mirrors
// the bash run_stage_security flow at stages/security.sh line-for-line:
//
//   1. Skip checks: SECURITY_AGENT_ENABLED, SKIP_SECURITY, IsDocsOnly.
//   2. Scan/rework loop bounded by SECURITY_MAX_REWORK_CYCLES.
//   3. Per cycle: render security_scan prompt → invoke agent → parse findings →
//      classify → escalate unfixable → rework fixable → build-gate.
//   4. Emit verdict + env exports.
package security

import (
    "context"
    "fmt"
    "io"
    "os"
    "path/filepath"
    "strconv"
    "time"

    "github.com/geoffgodwin/tekhton/internal/drift"
    "github.com/geoffgodwin/tekhton/internal/gates"
    "github.com/geoffgodwin/tekhton/internal/prompt"
    "github.com/geoffgodwin/tekhton/internal/proto"
    sec "github.com/geoffgodwin/tekhton/internal/security"
    "github.com/geoffgodwin/tekhton/internal/state"
    "github.com/geoffgodwin/tekhton/internal/supervisor"
)

// RunStage is the M34-pattern entry point. Returns a fully populated
// proto.StageResultV1 (Verdict, ExitReason, AgentCalls, HumanAction set).
// Never returns the zero result with a nil error — every code path either
// returns a valid result or an error.
func RunStage(ctx context.Context, req proto.StageRequestV1) (proto.StageResultV1, error) {
    cfg := loadConfig(req)
    log := newStageLogger(req.LogFile)  // writes "[security] ..." lines

    // --- Skip checks (order matches bash: agent-disabled → flag → docs-only) ---
    if !cfg.AgentEnabled {
        log("[security] Security stage disabled (SECURITY_AGENT_ENABLED=false). Skipping.")
        return result(proto.VerdictSkip, "agent_disabled"), nil
    }
    if cfg.SkipFlag {
        log("[security] Security stage skipped (--skip-security). Skipping.")
        return result(proto.VerdictSkip, "skip_flag"), nil
    }
    if docsOnly, _ := sec.IsDocsOnly(cfg.CoderSummaryFile); docsOnly {
        log("[security] All changed files are docs/config/assets. Skipping security scan.")
        return result(proto.VerdictSkip, "docs_only"), nil
    }

    // --- Scan/rework loop ---
    var (
        cycle      int
        agentCalls int
        findings   []sec.Finding
        humanAct   bool
    )

    sup := supervisor.New(causalForReq(req), state.ForReq(req))
    esc := sec.NewEscalator(cfg.ProjectDir, state.ForReq(req))

    for scanNeeded := true; scanNeeded; {
        scanNeeded = false
        // --- Invoke security agent ---
        scanRes, err := invokeScanAgent(ctx, sup, cfg, req)
        if err != nil {
            return result(proto.VerdictFail, "scan_failed"), err
        }
        agentCalls++
        log("[security] Security scan finished.")

        // --- Parse findings ---
        findings, err = sec.ParseReport(cfg.ReportFile)
        if err != nil {
            log(fmt.Sprintf("[security] Error parsing report: %v", err))
            return result(proto.VerdictFail, "report_parse_error"), err
        }
        if len(findings) == 0 {
            log(fmt.Sprintf("[security] No structured findings in %s. Proceeding.", cfg.ReportFile))
            return resultWithCounts(proto.VerdictPass, "no_findings", agentCalls, false, ""), nil
        }
        log(fmt.Sprintf("[security] Found %d finding(s).", len(findings)))

        // --- Classify ---
        fixable := sec.BuildFixableBlock(findings, cfg.BlockSeverity)
        unfixable := sec.BuildUnfixableBlock(findings, cfg.BlockSeverity)
        notes := sec.BuildNotesBlock(findings, cfg.BlockSeverity)

        // --- Write notes file ---
        if err := WriteNotesFile(cfg.NotesFile, notes, unfixable, cfg.UnfixablePolicy, cfg.Now()); err != nil {
            log(fmt.Sprintf("[security] Failed to write notes file: %v", err))
        }

        // --- Handle unfixable ---
        if unfixable != "" {
            cont, escErr := esc.HandleUnfixable(cfg.UnfixablePolicy, unfixable, cfg.Task)
            if escErr != nil {
                log(fmt.Sprintf("[security] Failed to record human-action escalation: %v", escErr))
                // matches bash: warn but continue
            }
            if !cont {
                // halt policy
                log("[security] Pipeline halted — unfixable CRITICAL/HIGH security findings detected.")
                log(fmt.Sprintf("[security] Review %s and resolve manually.", cfg.ReportFile))
                writeHaltState(req, cfg)
                return resultWithCounts(proto.VerdictBlock, "security_halt", agentCalls, true, ""), nil
            }
            if cfg.UnfixablePolicy == "escalate" || cfg.UnfixablePolicy == "" {
                humanAct = true
            }
        }

        // --- Route fixable to rework ---
        if fixable != "" && cycle < cfg.MaxRework {
            cycle++
            log(fmt.Sprintf("[security] Rework cycle %d / %d — fixing %s...",
                cycle, cfg.MaxRework, firstLine(fixable)))
            req2 := req
            if req2.EnvOverrides == nil {
                req2.EnvOverrides = map[string]string{}
            }
            req2.EnvOverrides["SECURITY_FIXABLE_BLOCK"] = fixable

            if _, err := invokeReworkAgent(ctx, sup, cfg, req2, cycle); err != nil {
                return result(proto.VerdictFail, "rework_failed"), err
            }
            agentCalls++

            // --- Post-rework build gate ---
            if err := gates.RunBuildGate(ctx, "security-rework"); err != nil {
                log(fmt.Sprintf("[security] Build gate failed after security rework. Proceeding to reviewer."))
                break
            }
            scanNeeded = true
        }
    }

    // --- Emit env exports for downstream stages ---
    findingsBlock := buildFindingsExport(findings)
    fixesBlock := ""
    if cycle > 0 {
        fixesBlock = fmt.Sprintf("Security rework applied %d cycle(s). Review %s for details of findings and fixes.",
            cycle, cfg.ReportFile)
    }
    writeStageEnvExports(req.ResultFile, map[string]string{
        "SECURITY_FINDINGS_BLOCK":     findingsBlock,
        "SECURITY_FIXES_BLOCK":        fixesBlock,
        "SECURITY_REWORK_CYCLES_DONE": strconv.Itoa(cycle),
    })

    log(fmt.Sprintf("[security] Security stage complete. Rework cycles: %d.", cycle))
    return resultWithCounts(proto.VerdictPass, "complete", agentCalls, humanAct, ""), nil
}
```

Helper functions referenced (`loadConfig`, `newStageLogger`, `result`, `resultWithCounts`, `firstLine`, `buildFindingsExport`, `writeStageEnvExports`, `writeHaltState`, `causalForReq`) are small utilities in `run.go` or sibling files. `state.ForReq(req)` is the M34-shipped helper that opens a state.Store for the project from a stage request — confirm at M35.2 design pass.

### Goal 2 — `internal/stages/security/scan.go` and `rework.go`

```go
// scan.go
func invokeScanAgent(ctx context.Context, sup *supervisor.Supervisor, cfg config, req proto.StageRequestV1) (*proto.AgentResultV1, error) {
    turns := clampTurns(cfg.MaxTurns, cfg.MinTurns, cfg.MaxTurnsCap, cfg.MilestoneMode)
    env := req.EnvOverrides
    if env == nil { env = map[string]string{} }
    // Pre-load previous report content so the prompt can reference it.
    if data, err := os.ReadFile(cfg.ReportFile); err == nil {
        env["SECURITY_REPORT_CONTENT"] = string(data)
    } else {
        env["SECURITY_REPORT_CONTENT"] = ""
    }
    body, err := prompt.Render("security_scan", env)
    if err != nil {
        return nil, fmt.Errorf("render security_scan: %w", err)
    }
    return sup.Run(ctx, &proto.AgentRequestV1{
        Role:     "Security (scan)",
        Model:    cfg.ScanModel,
        Turns:    turns,
        Prompt:   body,
        LogFile:  req.LogFile,
        Tools:    cfg.ReviewerTools,
    })
}

// rework.go
func invokeReworkAgent(ctx context.Context, sup *supervisor.Supervisor, cfg config, req proto.StageRequestV1, cycle int) (*proto.AgentResultV1, error) {
    body, err := prompt.Render("security_rework", req.EnvOverrides)
    if err != nil {
        return nil, fmt.Errorf("render security_rework: %w", err)
    }
    return sup.Run(ctx, &proto.AgentRequestV1{
        Role:     fmt.Sprintf("Security Rework (cycle %d)", cycle),
        Model:    cfg.CoderModel,
        Turns:    cfg.CoderMaxTurns,
        Prompt:   body,
        LogFile:  req.LogFile,
        Tools:    cfg.CoderTools,
    })
}
```

`clampTurns` mirrors bash lines 48-59: doubles when `MILESTONE_MODE=true`, clamps to `[MinTurns, MaxTurnsCap]`. `scanModel` defaults to `CLAUDE_SECURITY_MODEL || CLAUDE_STANDARD_MODEL || "claude-sonnet-4-6"`; `coderModel` to `CLAUDE_CODER_MODEL || "claude-sonnet-4-6"`.

### Goal 3 — `internal/stages/security/notes.go`

```go
package security

import (
    "fmt"
    "os"
    "strings"
    "time"
)

// WriteNotesFile mirrors _write_security_notes byte-for-byte. Skips when path
// is empty (matches the bash `${SECURITY_NOTES_FILE:-}` empty-default behavior).
func WriteNotesFile(path, notesBlock, unfixableBlock, policy string, now time.Time) error {
    if path == "" {
        return nil
    }
    var b strings.Builder
    b.WriteString("# Security Notes\n\n")
    b.WriteString("Generated: ")
    b.WriteString(now.Format("2006-01-02 15:04:05"))
    b.WriteString("\n\n")
    if notesBlock != "" {
        b.WriteString("## Non-Blocking Findings (MEDIUM/LOW)\n")
        b.WriteString(notesBlock)
        b.WriteString("\n")
    }
    if unfixableBlock != "" && policy == "waiver" {
        b.WriteString("## Waivered Findings\n")
        b.WriteString(unfixableBlock)
        b.WriteString("\n")
    }
    return os.WriteFile(path, []byte(b.String()), 0o644)
}
```

The byte layout is parity-tested in M35.3.

### Goal 5 — Bash file deletions

After the Go path is dogfooded clean (typically 1-3 dogfood runs producing `4.35.x` patch bumps), one delete commit:

```
git rm stages/security.sh
git rm lib/security_helpers.sh
```

The deletes are part of M35.2, not M35.3 — by the time M35.3 starts the bash should be gone. M35.3 is just the safety net + integration test work.

### Goal 6 — `cmd/tekhton/security.go` post-shim cleanup

After M35.2's bash-shim deletion, the `tekhton security handle-unfixable` subcommand has no caller — it was shim-only. Two options:

- **Delete it.** Cleanest. No bash code calls it; the Go stage calls `Escalator.HandleUnfixable` in-process.
- **Keep it Hidden.** Lets an operator manually escalate from a debugging shell. Low-cost insurance.

m35.2 design picks **delete** — operators have `tekhton drift human-action append` directly if they need to write escalations by hand. `parse-findings`, `meets-threshold`, `build-block`, `is-docs-only` stay (un-Hide the first two as user-facing tools; the others stay Hidden as debug-only).

### Goal 8 — Dogfooding expectations

Based on m32.3 (similar-size stage port — though m32 was bigger): expect 1-5 patch bumps during the m35.2 dogfood run. Notable risk surfaces to watch:

- The env-export passthrough (`SECURITY_FINDINGS_BLOCK`, `SECURITY_FIXES_BLOCK`) — confirm the M34 stage envelope handles per-stage env exports. If M34 didn't ship this seam, M35.2 must, and that's a scope-grow.
- The `MILESTONE_MODE` flag interaction with `MILESTONE_SECURITY_MAX_TURNS` — bash `MILESTONE_SECURITY_MAX_TURNS:-$(( security_turns * 2 ))` is doubly-defaulting (defaults to env-default of `SECURITY_MAX_TURNS`, then doubled). Easy to get wrong in Go.
- The `_write_security_notes` timestamp format — bash uses `date '+%Y-%m-%d %H:%M:%S'`; Go uses `time.Format("2006-01-02 15:04:05")`. Should match but operator dashboards may grep for it.

## Watch For

- **Severity-classification thresholds must match bash byte-for-byte.** M35.1 owns the predicate; M35.2 just calls it. Do not re-implement `MeetsThreshold` in the stage — call `sec.MeetsThreshold` and trust the M35.1 package.
- **`SECURITY_AGENT_ENABLED=false` must skip the stage entirely.** Order matters: the agent-disabled check is the FIRST skip check, before `SKIP_SECURITY`, before `IsDocsOnly`. If you reorder them (e.g. check docs-only first for performance), an operator who set `SECURITY_AGENT_ENABLED=false` because the security agent's quota is exhausted will still pay the coder-summary-read cost. Match bash order exactly.
- **The prompt template path stays the same — no template content changes.** Render `security_scan` and `security_rework` by name via `prompt.Render`. Do not inline template bodies into Go strings. `prompts/specialist_security.prompt.md` may also be referenced (it's the role-prompt the scan template ships to the agent); leave it on disk.
- **HUMAN_ACTION_REQUIRED.md escalation MUST use `internal/drift/artifacts.go::HumanAction.Append`** (via M35.1's `Escalator`). Do not call `drift.HumanAction.Append` directly from the stage — go through `Escalator.HandleUnfixable`. The M35.1 indirection is what enforces the policy dispatch.
- **The halt branch writes pipeline state.** Bash `_handle_unfixable_findings` halt branch calls `write_pipeline_state "security" "security_halt" ...`. M35.1 deliberately moved state-write responsibility to the stage (because state is stage-owned, not helper-owned). M35.2's `writeHaltState(req, cfg)` call is what reproduces this. Forgetting it means a halted pipeline can't be resumed — operators lose `tekhton run --start-at security`.
- **The post-rework build gate's "break" semantics matter.** Bash line 138-141: if `run_build_gate` returns non-zero, warn and break the loop (NOT fail the stage). The Go port preserves this — `gates.RunBuildGate` returning error should warn-log and break the for-loop, then proceed to emit the Pass verdict with whatever cycle count was reached. A build-gate failure post-rework is "best effort done, move on", not a stage failure.
- **The `MILESTONE_SECURITY_MAX_TURNS` default is doubly-defaulting.** Bash: `security_turns="${MILESTONE_SECURITY_MAX_TURNS:-$(( security_turns * 2 ))}"`. The Go translation: `if MilestoneMode && MilestoneSecurityMaxTurns == "" { turns = securityTurns * 2 } else if MilestoneMode { turns = parseInt(MilestoneSecurityMaxTurns) }`. Easy to bungle — write a table test that exercises both branches.
- **`SECURITY_NOTES_FILE` may be unset.** Bash silently swallows the failed `> ""` redirect. The Go port explicitly skips when path is empty (`WriteNotesFile` line 1). Do not `os.WriteFile("", ...)` — that errors. Tested by an empty-path test case.
- **The supervisor's `run_agent` shape vs bash `run_agent`.** Bash positional args: `role model turns prompt log_file tools`. Go `proto.AgentRequestV1`: named fields. The mapping is mechanical but the M34 RunStage in `internal/stages/intake` should be the reference — copy its convention. Drifting from M34 here creates a stage-to-stage inconsistency that's painful to clean up later.
- **The `cmd/tekhton/security.go::handle-unfixable` deletion is a contract change.** If any external operator tooling shells out to `tekhton security handle-unfixable`, that breaks. Survey before deleting; if anyone depends on it, keep it Hidden instead. The conservative call is to keep it Hidden — but it has cost zero callers historically.
