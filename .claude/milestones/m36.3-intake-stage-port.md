## Design

### Sequencing note

m36.3 is where the M36 arc closes. The deliverables cannot be reordered:

1. **Land `internal/stages/intake/` first.** intake.go + context.go + tests must compile and pass against fixtures before any bash file deletes.
2. **Register `GoImpl: intake.RunStage` second.** Once registered, the GoAdapter dispatcher routes intake invocations to Go and the bash file becomes unreachable.
3. **Delete the three bash files third.** Pre-delete: parity gate runs against the Go entry via GoAdapter. Post-delete: parity gate still runs.
4. **Drop the `Helpers` array entries fourth.** With `lib/intake_helpers.sh` and `lib/intake_verdict_handlers.sh` gone, the `Helpers: []string{...}` entries in `DefaultStageDefs[proto.StageIntake]` would cause a 127 exit if any fallback path ever reaches bash. Remove them.
5. **Delete the M36.2 transition CLI shim fifth.** With no bash caller left for `tekhton intake helpers|verdict ...`, the shim has no purpose. Delete `cmd/tekhton/intake.go` + drop the registration from `cmd/tekhton/main.go`.
6. **Wedge-audit + VERSION + docs last.**

Reversing 1↔2 or 2↔3 breaks the pipeline mid-run.

### Goal 1 — `internal/stages/intake/intake.go` shape

```go
package intake

import (
    "context"
    "github.com/geoffgodwin/tekhton/internal/agent"
    "github.com/geoffgodwin/tekhton/internal/causal"
    "github.com/geoffgodwin/tekhton/internal/clarify"
    pkgintake "github.com/geoffgodwin/tekhton/internal/intake"
    "github.com/geoffgodwin/tekhton/internal/notes"
    "github.com/geoffgodwin/tekhton/internal/prompt"
    "github.com/geoffgodwin/tekhton/internal/proto"
    "github.com/geoffgodwin/tekhton/internal/state"
)

func RunStage(ctx context.Context, req *proto.StageRequestV1) (*proto.StageResultV1, error) {
    log := stageLogger(req)

    // 1. Pipeline-start cleanup: clear sentinel files. Sole owner.
    cleanupSentinels(req)

    // 2. Disabled-agent skip.
    if envBool(req, "INTAKE_AGENT_ENABLED", true) == false {
        log.Info("Intake agent disabled (INTAKE_AGENT_ENABLED=false). Skipping.")
        return passResult(req, "disabled"), nil
    }

    // 3. HUMAN_MODE skip. Notes are pre-triaged; do not run clarity eval.
    if envBool(req, "HUMAN_MODE", false) {
        log.Info("Intake: skipped in --human mode (notes are pre-triaged by user).")
        return passResultWithExports(req, "human_mode", map[string]string{
            "INTAKE_VERDICT":    "PASS",
            "INTAKE_CONFIDENCE": "100",
        }), nil
    }

    h := newHelpers(req)
    vh := newVerdictHandler(req, h)
    reportFile := envOrDefault(req, "INTAKE_REPORT_FILE", ".tekhton/INTAKE_REPORT.md")

    // 4. Cached-run branch (dry-run).
    if envBool(req, "INTAKE_CACHED", false) && fileExists(reportFile) {
        log.Header("Pre-stage 1 — Task Intake (cached)")
        log.Info("Intake: using cached results from dry-run.")
        verdict := h.ParseVerdict(reportFile)
        confidence := h.ParseConfidence(reportFile)
        log.Info("Intake verdict: %s (confidence: %d)", verdict, confidence)
        return dispatchVerdict(ctx, vh, verdict, reportFile, confidence, req)
    }

    // 5. Get content + skip if unchanged.
    content, err := h.MilestoneContent(envBool(req, "MILESTONE_MODE", false),
        env(req, "_CURRENT_MILESTONE"), env(req, "TASK"))
    if err != nil { return failResult(req, err), err }
    if content == "" {
        log.Info("Intake: no content to evaluate. Passing.")
        return passResult(req, "no_content"), nil
    }

    hash := h.ContentHash(content)
    if h.ShouldSkip(hash) {
        log.Info("Intake: content unchanged since last evaluation. Skipping.")
        return passResult(req, "unchanged"), nil
    }

    // 6. Banner + prompt vars.
    log.Header("Pre-stage 1 — Task Intake")

    promptVars := buildPromptVars(req, content, h)

    // 7. Render + invoke.
    promptText, err := prompt.Render("intake_scan", promptVars)
    if err != nil { return failResult(req, err), err }

    log.Info("Running intake evaluation (model: %s, turns: %d)...",
        env(req, "CLAUDE_INTAKE_MODEL"), envInt(req, "INTAKE_MAX_TURNS", 10))

    agentRes := agent.Run(ctx, agent.Spec{
        Name: "Intake",
        Model: envOrDefault(req, "CLAUDE_INTAKE_MODEL", "claude-sonnet-4-6"),
        MaxTurns: envInt(req, "INTAKE_MAX_TURNS", 10),
        Prompt: promptText,
        LogFile: req.LogFile,
    })

    // 8. Parse + record hash.
    verdict := h.ParseVerdict(reportFile)
    confidence := h.ParseConfidence(reportFile)
    log.Info("Intake verdict: %s (confidence: %d)", verdict, confidence)
    h.SaveHash(hash)

    // 9. Dispatch.
    return dispatchVerdict(ctx, vh, verdict, reportFile, confidence, req)
}

func dispatchVerdict(ctx context.Context, vh *pkgintake.VerdictHandler,
    verdict, reportFile string, confidence int, req *proto.StageRequestV1) (*proto.StageResultV1, error) {

    exports := map[string]string{
        "INTAKE_VERDICT":    verdict,
        "INTAKE_CONFIDENCE": fmt.Sprintf("%d", confidence),
    }

    switch verdict {
    case "PASS":
        // M118: defer the success line to the caller — set the flag, return.
        exports["_INTAKE_PASS_EMIT"] = "true"
        return passResultWithExports(req, "pass", exports), nil
    case "TWEAKED":
        if err := vh.HandleTweaked(reportFile); err != nil {
            return failResult(req, err), err
        }
    case "SPLIT_RECOMMENDED":
        if err := vh.HandleSplitRecommended(reportFile); err != nil {
            return failResult(req, err), err
        }
    case "NEEDS_CLARITY":
        if err := vh.HandleNeedsClarity(reportFile); err != nil {
            return failResult(req, err), err
        }
    }
    return passResultWithExports(req, verdictExitReason(verdict), exports), nil
}
```

`notes.Extract()` is the m24 ported function; calling it as a Go API replaces the `tekhton note extract` exec in the bash version (lines 154-155). One subprocess elimination.

The keyword-overlap matcher (4-char minimum + case-insensitive substring + word-set extraction from task) ports as:

```go
func matchNotes(task string, allNotes []string) []string {
    taskWords := extractWords(task, 4)
    var matching []string
    for _, note := range allNotes {
        lower := strings.ToLower(note)
        for _, w := range taskWords {
            if strings.Contains(lower, w) {
                matching = append(matching, note)
                break
            }
        }
    }
    return matching
}

func extractWords(s string, minLen int) []string {
    re := regexp.MustCompile(`[a-z]{` + strconv.Itoa(minLen) + `,}`)
    return uniqueSorted(re.FindAllString(strings.ToLower(s), -1))
}
```

### Goal 4 — `_INTAKE_PASS_EMIT` deferred-emit flag

Bash lines 217-225 (M118) defer the PASS success line to the caller because the TUI pill must flip green BEFORE the success line lands in Recent Events. The Go port preserves this by setting `_INTAKE_PASS_EMIT=true` on the PASS path and `false` (omitted) on the early-exit paths (disabled, HUMAN_MODE, no content, unchanged, cached).

The result envelope returned from `RunStage` carries the export via `result.Exports["_INTAKE_PASS_EMIT"]`. The stagerunner adapter writes these into the TEKHTON_STAGE_RESULT_FILE; tekhton-legacy.sh sources the exports back into the environment after the stage call returns. M34/M35 established this pattern; M36.3 only adds a new export key.

### Goal 5 — Parity gate (`tests/test_intake_parity.sh`)

Six scenarios:

1. **`pass`** — milestone fixture that the mock agent returns PASS for. Assert: `INTAKE_VERDICT=PASS`, `INTAKE_CONFIDENCE=85` (matches fixture), `_INTAKE_PASS_EMIT=true`, no clarifications file written, no milestone mutation.
2. **`tweaked`** — milestone fixture, mock agent returns TWEAKED with a 80%-size tweak. Assert: milestone file replaced (atomic), `.pre-tweak` backup exists, PM-tweaked comment present, `INTAKE_VERDICT=TWEAKED`.
3. **`tweaked-rejected`** — milestone fixture (100 lines), mock agent returns TWEAKED with a 10-line tweak. Assert: `ErrTweakRejected` path taken, milestone unchanged, `<SessionDir>/REJECTED_TWEAK.md` exists with tweak content.
4. **`split-recommended`** — milestone fixture, mock agent returns SPLIT_RECOMMENDED, INTAKE_AUTO_SPLIT=true. Assert: split-milestone CLI invoked, switch-sub-milestone invoked, `INTAKE_VERDICT=SPLIT_RECOMMENDED`.
5. **`needs-clarity`** — milestone fixture, mock agent returns NEEDS_CLARITY with three questions, COMPLETE_MODE=false. Assert: CLARIFICATIONS.md byte-identical to `internal/intake/testdata/clarifications_golden.md` (after timestamp normalization), `tekhton clarify handle` invoked.
6. **`needs-clarity-complete-mode`** — same fixture, COMPLETE_MODE=true. Assert: CLARIFICATIONS.md written, pipeline state saved with `needs_clarity` exit reason, `tekhton clarify handle` NOT invoked.

Two additional skip-branch scenarios:

7. **`human-mode-skip`** — HUMAN_MODE=true. Assert: stage logs "Intake: skipped in --human mode...", exports INTAKE_VERDICT=PASS / INTAKE_CONFIDENCE=100, no agent invoked.
8. **`cached-run`** — INTAKE_CACHED=true + report file present. Assert: cached header logged, verdict and confidence loaded from cache, no agent invoked.

The parity gate uses a mock agent (a small bash harness that writes a canned `INTAKE_REPORT.md` instead of calling the real Claude API) and wires into `make dogfood`.

### Goal 7 — `run_intake_create` deferral

The `--add-milestone` create-mode entry (`stages/intake.sh:244-377`) stays bash for now. M36.3 deletes `stages/intake.sh` — `run_intake_create` therefore disappears alongside. **This is a known regression for `--add-milestone`**: the create flow stops working at M36.3 close. A follow-up milestone (m36.4 candidate) ports it.

To prevent silent breakage between M36.3 close and the follow-up, `tekhton-legacy.sh`'s `--add-milestone` early-check gets a stub:

```bash
if [[ "$1" == "--add-milestone" ]]; then
    error "--add-milestone is temporarily unavailable post-m36.3. Tracked as a Phase 5 follow-up." >&2
```

## Watch For

- **Delete order matters.** Land Go entry → register `GoImpl` → delete the three bash files → drop the `Helpers` entries → delete the M36.2 CLI shim → audit + docs + VERSION. Deleting the bash files before registering `GoImpl` means the stagerunner attempts to source missing files and exits 127.
- **`--add-milestone` create mode is a known regression at M36.3 close.** `run_intake_create` lives only in `stages/intake.sh`; deleting the file deletes the function. The stub in `tekhton-legacy.sh` returns a clear error pointing to the follow-up milestone. Do NOT silently break — operators who rely on `--add-milestone` need a clear "temporarily unavailable" message.
- **`_INTAKE_PASS_EMIT` is only set on PASS, never on the skip paths.** Bash lines 217-225 (M118) flag this explicitly: HUMAN_MODE, disabled, no content, unchanged, cached early-exits set `INTAKE_VERDICT=PASS` but do NOT set `_INTAKE_PASS_EMIT`. Preserve the asymmetry — the TUI relies on the flag presence to decide whether to defer the success line.
- **The sentinel cleanup at stage entry is the sole owner.** `${TEKHTON_DIR}/.final_check_result` and `${TEKHTON_DIR}/.commit_decision` are cleared here and nowhere else (the bash comment at lines 36-44 makes this explicit). The Go port preserves the single-owner invariant. Other stages WRITE them; only intake CLEARS them at pipeline-start.
- **`INTAKE_CLARITY_THRESHOLD` is NOT enforced by the stage.** The threshold injects into the prompt as a template variable (the agent decides the verdict). Adding a Go-side `if confidence < threshold { verdict = NEEDS_CLARITY }` would double-gate and break the agent contract. The wedge-audit could grep for `INTAKE_CLARITY_THRESHOLD` references inside `internal/stages/intake/` and reject any conditional usage.
- **Parity gate runs against a mock agent.** The real Claude API is not invoked in CI — the parity harness writes canned `INTAKE_REPORT.md` files keyed by scenario. The mock agent contract: `tests/fixtures/intake/mock_agent.sh` writes `$INTAKE_REPORT_FILE` from `$INTAKE_SCENARIO` and exits 0. The Go test harness sets `INTAKE_SCENARIO` per scenario.
- **The byte-for-byte CLARIFICATIONS.md format is the M36.2 contract.** M36.2's `internal/intake/testdata/clarifications_golden.md` is the source of truth. M36.3 must produce a file byte-identical to that golden (after timestamp normalization in the parity-gate diff). If M36.3's output differs, fix M36.3 — not the golden file.
- **The architect (m36.1) parity gate must still pass at m36.3 close.** No code changes in `internal/stages/architect/` during m36.3 should regress the m36.1 parity gate. CI runs both gates on every PR.
- **`internal/intake/` package usage stays in-process.** No subprocess execs into `tekhton intake helpers ...` from `internal/stages/intake/` — that was the M36.2 transition shape. M36.3 imports `internal/intake` as a Go package and calls the methods directly.
- **`tekhton-legacy.sh` may have direct `source lib/intake_helpers.sh` lines.** If so, drop them. The stagerunner sources only what `DefaultStageDefs[stage].Helpers` lists; with M36.3 setting `Helpers: nil` for `StageIntake`, no helper sourcing happens. Verify by `grep -nE 'intake_(helpers|verdict)' tekhton-legacy.sh` returning zero matches.
