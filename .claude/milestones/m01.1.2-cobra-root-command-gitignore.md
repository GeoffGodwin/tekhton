#### Milestone 1.1.2: Cobra Root Command + .gitignore

Wire Cobra into the existing `main.go` so the binary exposes proper `--version` and `--help` flags and exits non-zero on bare invocation. Add `.gitignore` entries for build artifacts. The Makefile and version package from 1.1.1 are reused unchanged.

Files to modify:
- `cmd/tekhton/main.go` (replace plain main with Cobra root command)
- `.gitignore` (add `bin/` and `*.test`)

Files to create:
- `go.sum` (populated by `go mod tidy` after adding Cobra dep)

Acceptance criteria:
- `go.mod` gains a `require github.com/spf13/cobra` entry and `go.sum` is committed.
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION` (same output as 1.1.1's bare invocation).
- `bin/tekhton --help` produces standard Cobra output (Usage, Flags sections).
- Bare `bin/tekhton` invocation exits non-zero and emits the help text.
- Direct `go build ./cmd/tekhton` (without make) still leaves `Version` at the `dev` sentinel; `--version` reflects that.
- `make build` continues to inject the real version via `-ldflags "-X"`.
- `make test` exits 0.
- `.gitignore` contains both `bin/` and `*.test` on their own lines.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Use `cobra.Command.Version` + `SetVersionTemplate` (or a custom `--version` flag) so the printed string is exactly the trimmed `VERSION` contents — Cobra's default `program version X` template adds a prefix that breaks the acceptance criterion.
- Wire `RunE` (or `Run`) so that bare invocation prints help AND returns a non-zero exit code; Cobra's default prints help with exit 0.
- Run `go mod tidy` so `go.sum` is complete; partial sums break CI.
- Do NOT remove `CGO_ENABLED=0` from the Makefile when retesting.
- Trailing whitespace on `VERSION` must still be trimmed after the Cobra refactor.

Seeds Forward:
- Milestone 1.2 depends on the Makefile (untouched here) to add `build-all` cross-compile target.
- Milestone 1.3 depends on `bin/tekhton --version` working for the self-host assertion.
