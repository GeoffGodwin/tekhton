#### Milestone 1.1: Go Module + Cobra Binary

Bootstrap the Go module at the repo root and create the Cobra root command with `--version` support. This is the foundation — the binary must build locally before any CI or self-host harness can use it. Ships zero runtime callability into bash code paths.

Files to create:
- `go.mod` (module path `github.com/geoffgodwin/tekhton`, pin `go 1.23`)
- `go.sum`
- `cmd/tekhton/main.go` (Cobra root, no subcommands, `--version` flag, ~40 lines)
- `internal/version/version.go` (exported `Version` var defaulting to `"dev"`, `String()` trims whitespace)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go build -ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(cat VERSION)" -o bin/tekhton ./cmd/tekhton` succeeds on a clean checkout.
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`.
- `bin/tekhton --help` produces standard Cobra output; any other invocation prints help and exits non-zero.
- `go vet ./...` clean.
- Direct `go build` (without ldflags) leaves `Version` at the `dev` sentinel.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- `//go:embed ../../VERSION` is invalid Go — `embed` paths cannot traverse out of the source file's directory. Use ldflags injection.
- Only dependency in `go.mod` should be `spf13/cobra` — no transitive cgo pulls.
- The ldflags target path is the fully-qualified package symbol: `github.com/geoffgodwin/tekhton/internal/version.Version`, not `main.version`.

Seeds Forward:
- Milestone 1.2 wraps `go build` in a Makefile and adds cross-compile targets.
- Milestone 1.3 depends on `bin/tekhton --version` being functional for the self-host assertion.
- m02 will add the first subcommand (`tekhton causal emit`) wired through this Cobra root.
