# m36.1 — Architect Stage Port

## Overview

| Item | Detail |

| **Arc motivation** | First child of M36. Ports the architect pre-stage gate (the drift audit + ADL remediation router) to Go. ## Design

### Sequencing note

m36.1 lands before m36.2 (intake helpers) and m36.3 (intake stage) because the architect is independent of intake — the two share no helpers. Landing architect first validates the pre-stage gate port pattern at a thinner surface (architect is single-prompt-with-three-rework-variants; intake is four-verdict-router). Any pattern adjustment surfaced by m36.1 informs m36.2/m36.3 without forcing a roll-back.

### Goal 1 — `RunStage` entry shape

```go
// internal/stages/architect/architect.go
package architect

import (
    "context"
    "github.com/geoffgodwin/tekhton/internal/drift"
    "github.com/geoffgodwin/tekhton/internal/prompt"
    "github.com/geoffgodwin/tekhton/internal/agent"
    "github.com/geoffgodwin/tekhton/internal/gates"
    "github.com/geoffgodwin/tekhton/internal/proto"
)

func RunStage(ctx context.Context, req *proto.StageRequestV1) (*proto.StageResultV1, error) {
    log := stageLogger(req)
    log.Header("Pre-stage 2 — Architect Audit")

    // 1. Load drift / ADL context (via internal/drift cached reads).
    driftLog, _ := drift.ReadLog(req.ProjectDir)
    adlLog, _ := drift.ReadADL(req.ProjectDir)
    archDoc, _ := drift.ReadArchitectureDoc(req.ProjectDir)
    obsCount, _ := drift.Count(req.ProjectDir)

    // 2. Render and invoke architect agent.
    promptText, err := prompt.Render("architect", promptVars(req, driftLog, adlLog, archDoc, obsCount))
    if err != nil { return failResult(req, err), err }

    res := agent.Run(ctx, agent.Spec{
        Name: "Architect",
        Model: architectModel(req),
        MaxTurns: architectMaxTurns(req),
        Prompt: promptText,
        Tools: agentToolsArchitect(req),
        LogFile: req.LogFile,
    })
    if res.ErrorCategory == "UPSTREAM" {
        log.Warn("Architect hit API error (%s): %s", res.ErrorSubcategory, res.ErrorMessage)
        return passResult(req, "upstream_error"), nil
    }

    // 3. Validate output.
    planPath := architectPlanPath(req)
    if !fileExists(planPath) {
        log.Warn("Architect did not produce %s. Skipping remediation.", planPath)
        return passResult(req, "no_plan"), nil
    }

    // 4. Parse plan + route.
    plan, err := parsePlan(openFile(planPath))
    if err != nil { return failResult(req, err), err }

    if plan.HasSimplification() {
        runRework(ctx, "sr_rework", req)
    }
    if plan.HasJrWork() {
        runRework(ctx, "jr_rework", req)
    }
    if plan.HasSimplification() || plan.HasJrWork() {
        if err := runPostRemediationGates(ctx, req); err != nil {
            // Bash returns 0 after a build-broken warning; preserve.
            drift.ResetAudit(req.ProjectDir)
            return passResult(req, "build_broken"), nil
        }
    }

    // 5. Resolve drift entries + re-add OOS items.
    preCount, _ := drift.Count(req.ProjectDir)
    if preCount > 0 {
        oosItems := plan.OutOfScope()
        drift.ResolveAll(req.ProjectDir)
        if len(oosItems) > 0 {
            drift.AddEntries(req.ProjectDir, oosItems)
        }
    }

    // 6. Surface Design Doc Observations.
    for _, obs := range plan.DesignDocObservations() {
        drift.AppendHumanAction(req.ProjectDir, "architect", obs)
    }

    // 7. Reset audit counter + archive plan.
    drift.ResetAudit(req.ProjectDir)
    archivePlan(planPath, req)

    return passResult(req, "audit_complete"), nil
}
```

### Goal 2 — `plan_parser.go` shape

```go
type parsedPlan struct {
    Simplification     []string
    StalenessFixes     []string
    DeadCodeRemoval    []string
    NamingNormalization []string
    OutOfScopeRaw      []string  // post-multiline join, pre-filter
    DesignDocRaw       []string  // post-multiline join, pre-filter
}

func parsePlan(r io.Reader) (parsedPlan, error)
func (p *parsedPlan) HasSimplification() bool
func (p *parsedPlan) HasJrWork() bool
func (p *parsedPlan) OutOfScope() []string       // post-filter (bash lines 295-303)
func (p *parsedPlan) DesignDocObservations() []string // post-filter (bash lines 360-377)
```

The filter chains port as `var filterPatterns = []*regexp.Regexp{ ... }` with one entry per bash `grep -qiE` line. A table-test in `plan_parser_test.go` feeds a fixture-per-filter and asserts the bullet is excluded.

Multi-line bullet handling (bash lines 269-303) — accumulate continuation lines into the previous bullet when the line doesn't start with `-` / `*` — ports as a small state machine. Test against `testdata/plan_baseline.md` which contains 3-line bullets.

### Goal 3 — Sr/Jr remediation router

```go
// internal/stages/architect/remediation.go
func runRework(ctx context.Context, kind string, req *proto.StageRequestV1) error {
    switch kind {
    case "sr_rework":
        promptText, _ := prompt.Render("architect_sr_rework", remVars(req))
        return agent.Run(ctx, agent.Spec{
            Name: "Coder (architect remediation)",
            Model: env(req, "CLAUDE_CODER_MODEL", "claude-sonnet-4-6"),
            MaxTurns: envInt(req, "CODER_MAX_TURNS", 80),
            Prompt: promptText,
            Tools: env(req, "AGENT_TOOLS_CODER", ""),
            LogFile: req.LogFile,
        }).Err()
    case "jr_rework":
        promptText, _ := prompt.Render("architect_jr_rework", remVars(req))
        return agent.Run(ctx, agent.Spec{
            Name: "Jr Coder (architect remediation)",
            Model: env(req, "CLAUDE_JR_CODER_MODEL", "claude-sonnet-4-6"),
            MaxTurns: envInt(req, "JR_CODER_MAX_TURNS", 40),
            Prompt: promptText,
            Tools: env(req, "AGENT_TOOLS_JR_CODER", ""),
            LogFile: req.LogFile,
        }).Err()
    }
    return nil
}
```

Sr handles **only** the Simplification section; jr handles Staleness + Dead Code + Naming. The bash split (lines 160-194) is preserved. Operators tune `CLAUDE_CODER_MODEL` and `CLAUDE_JR_CODER_MODEL` independently — the Go port keeps the dispatch separate.

### Goal 4 — Post-remediation build + expedited review

The bash sequence at lines 196-251:

1. `run_build_gate "post-architect-remediation"` (already Go via m31 — call as `gates.RunBuild(ctx, ...)`).
2. On failure: render `build_fix_minimal`, run a coder agent with `CODER_MAX_TURNS / 3`, then retry the build gate.
3. On still-failed: warn, reset audit, return 0.
4. On pass: render `architect_review`, run reviewer agent.

This ports verbatim. The `CODER_MAX_TURNS / 3` integer division is preserved (bash uses `$((CODER_MAX_TURNS / 3))`).

### Goal 5 — Drift integration boundary

All drift-related writes route through `internal/drift/`:

- `drift.Count(projectDir) (int, error)` — replaces `tekhton drift count`
- `drift.ResolveAll(projectDir) error` — replaces `tekhton drift resolve-all`
- `drift.AddEntries(projectDir, entries []string) error` — replaces `tekhton drift entries --entry ... --entry ...`
- `drift.AppendHumanAction(projectDir, source, description string) error` — replaces `tekhton drift human-action append --source ... --description ...`
- `drift.ResetAudit(projectDir) error` — replaces `tekhton drift reset-audit`

These are existing functions in `internal/drift/` (M25-shipped). M36.1 wires them up in-process. The wedge-audit gains a check:

```bash
# M36.1 — forbid direct writes to drift-owned files from the architect stage package.
if grep -rE 'os.WriteFile|os.Create' internal/stages/architect/ | \
   grep -E 'ARCHITECTURE_LOG|DRIFT_LOG|HUMAN_ACTION_REQUIRED' >/dev/null 2>&1; then
    echo "FAIL: internal/stages/architect/ writes drift-owned files directly." >&2
    echo "  Use internal/drift/ entrypoints (M25 owns the file format)." >&2
    exit 1
fi
```

### Goal 6 — Parity gate (`tests/test_architect_parity.sh`)

Three scenarios:

1. **`audit-with-simplification`** — drift log has 5 entries, plan has Simplification section. Assert: sr coder dispatched once, jr coder NOT dispatched, build gate runs, expedited review runs, drift count goes 5 → 0 (or 5 → N where N is OOS items), HUMAN_ACTION_REQUIRED.md unchanged.
2. **`audit-with-jr-work-only`** — drift log has 3 entries, plan has Staleness Fixes only. Assert: sr NOT dispatched, jr dispatched once, drift count 3 → 0.
3. **`audit-with-design-doc-observations`** — drift log has 2 entries, plan has Design Doc Observations with 2 actionable + 1 boilerplate. Assert: HUMAN_ACTION_REQUIRED.md gains exactly 2 entries (boilerplate filtered), audit-counter reset.

Each scenario uses `internal/stages/architect/testdata/` fixtures + a mock agent (bash test harness writes a canned ARCHITECT_PLAN.md instead of calling the real Claude API).

### Goal 7 — TUI lifecycle preservation

Bash lines 80-84 / 100-105 / 113-117 / 217-224 / 401-411 — `_tui_call stage-begin --label architect ...`, `substage-begin --label architect-remediation`, `stage-end --verdict <X>` — preserve byte-for-byte. The Go port calls `internal/tui.CallStage("begin", "architect", ...)` etc. (m23 already ported tui write surface). Verdict strings used: `UPSTREAM_ERROR`, `NO_PLAN`, `BUILD_BROKEN`, `audit_complete`. Each is operator-visible in the TUI pill row.

## Watch For

- **Four prompt templates stay on disk; only the renderer caller moves.** `prompts/architect.prompt.md`, `architect_review.prompt.md`, `architect_sr_rework.prompt.md`, `architect_jr_rework.prompt.md` are operator-edited config — do NOT inline them as Go string literals. The m15 prompt engine (already Go) reads them; M36.1 just calls `prompt.Render("architect_sr_rework", ...)`.
- **Senior/junior split must be preserved.** Sr handles Simplification ONLY; Jr handles Staleness + Dead Code + Naming. The bash code (lines 160-194) routes each independently with its own model and max-turns. Do not merge the two `run_agent` calls into a single dispatch — operators tune the two models separately (`CLAUDE_CODER_MODEL` vs `CLAUDE_JR_CODER_MODEL`).
- **Drift writes go through `internal/drift/`, not direct file IO.** The wedge-audit extension in this milestone enforces this. M25 owns the file format and lock semantics for `ARCHITECTURE_LOG.md`, `DRIFT_LOG.md`, `HUMAN_ACTION_REQUIRED.md`. Direct `os.WriteFile` from `internal/stages/architect/` against any of those paths fails the audit.
- **The `Out of Scope` re-add path is critical.** After `drift.ResolveAll` zeros the drift log, the architect must re-add any items the plan marked "Out of Scope" so they reappear on the next audit. The bash code (lines 260-320) does this with awk + a multi-line-bullet-join + a filter chain. Port verbatim. Missing this means OOS items silently drop on the architect's first audit and never come back.
- **The Design Doc Observations filter chain is long and operator-vocabulary.** Eight `grep -qiE` patterns at lines 363-376 exclude boilerplate ("Design observations have been documented", "All items are recorded", etc.). Port each as a `regexp.MustCompile` and table-test one fixture per pattern. Missing a filter means HUMAN_ACTION_REQUIRED.md fills with meta-noise, which retros count as a regression.
- **Architect runs ONLY when promoted by `get_run_stage_plan`.** The dispatcher (in tekhton-legacy.sh) gates architect on drift thresholds or `--force-audit`. The Go RunStage MUST NOT add its own gating — it assumes the dispatcher already decided. If the dispatcher invokes architect, run.
- **TUI lifecycle calls preserve verdict strings byte-for-byte.** `UPSTREAM_ERROR`, `NO_PLAN`, `BUILD_BROKEN` are TUI pill labels — operators see them in the dashboard. Do not paraphrase.
- **`stages/architect.sh` deletion happens AFTER the parity gate passes.** Pre-delete: parity gate runs against the new Go entry via the stagerunner. Post-delete: parity gate still runs against the Go entry. No bash baseline is needed because the architect is independent of the bash run — the parity gate captures Go-vs-Go byte-identical replay against fixtures.
