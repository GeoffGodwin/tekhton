### Goal 1 — `RunStage` entry point

```go
// internal/stages/review/run.go
package review

import (
    "context"
    "fmt"

    "github.com/geoffgodwin/tekhton/internal/proto"
    reviewparse "github.com/geoffgodwin/tekhton/internal/review"
)

// RunStage is the GoImpl entry registered with stagerunner.StageDef.GoImpl for
// the review stage. Owns the full cycle loop end-to-end: returns once with a
// terminal verdict + cycle count, NOT once per cycle.
//
// Ports stages/review.sh::run_stage_review (385 LOC). Cycle loop placement
// decision per m37 parent: loop stays in-stage for M37; hoist into
// internal/orchestrate is a post-M39 candidate, not a wedge concern.
func RunStage(ctx context.Context, req *proto.StageRequestV1) (*proto.StageResultV1, error) {
    // Skip heuristics — bash lines 14-36.
    if shouldSkipPolish(req) {
        return approvedWithNotes(req, "skipped_polish_mode", map[string]string{"reviewer_skipped": "true"}), nil
    }
    if reason, skip := shouldSkipBySize(req); skip {
        return approvedWithNotes(req, "skipped_diff_threshold", map[string]string{
            "reviewer_skipped":    "true",
            "skip_threshold":      reason.Threshold,
            "skip_diff_lines":     reason.DiffLines,
        }), nil
    }

    estimatePostCoderTurns(ctx, req)  // bash line 38 — wraps existing helper if Go equivalent exists

    budget := reviewparse.CycleBudget{Max: maxReviewCycles(req)}
    var lastReport *reviewparse.Report
    var bumpedReviewerTurns int  // 0 means no bump in effect

    for budget.Current < budget.Max {
        budget.Increment()  // bash line 44

        cycleOut, err := runOneCycle(ctx, req, &budget, bumpedReviewerTurns)
        if err != nil {
            return nil, err  // hard error from agent infra; runner translates
        }

        // Apply the in-cycle turn-budget recalibration for the NEXT iteration.
        if newLimit, bumped := budget.BumpFromUsage(cycleOut.TurnsUsed, cycleOut.ReviewerLimit, reviewerCap(req)); bumped {
            bumpedReviewerTurns = newLimit
        }

        switch cycleOut.Decision {
        case cycleAccept:
            lastReport = cycleOut.Report
            return finalizeApproved(ctx, req, lastReport, budget)
        case cycleReplanAbort:
            return failResult(req, "replan_user_aborted", budget, cycleOut.Metadata), nil
        case cycleReplanContinue:
            // bash line 235 — verdict overridden to APPROVED_WITH_NOTES.
            return finalizeApproved(ctx, req, &reviewparse.Report{Verdict: reviewparse.VerdictApprovedWithNotes}, budget)
        case cycleUpstreamErrorAtMax:
            return failResult(req, "upstream_error", budget, cycleOut.Metadata), nil
        case cycleNullRunAtMax:
            return failResult(req, "null_run", budget, cycleOut.Metadata), nil
        case cycleSynthesizedAtMax:
            // bash lines 192-213 — synthesize report, trip commit gate, treat as APPROVED_WITH_NOTES.
            return synthesizedResult(req, budget), nil
        case cycleRework:
            lastReport = cycleOut.Report
            if err := runRework(ctx, req, lastReport, budget); err != nil {
                return reworkFailureResult(req, budget, err), nil  // bash lines 335-369 cover this
            }
            continue
        }
    }

    // Max cycles exhausted with blockers remaining — bash lines 354-368.
    return blockersRemainResult(req, lastReport, budget), nil
}
```

### Goal 2 — `runOneCycle` — single-cycle work

```go
// internal/stages/review/cycle.go
package review

type cycleDecision int

const (
    cycleAccept cycleDecision = iota
    cycleReplanAbort
    cycleReplanContinue
    cycleUpstreamErrorAtMax
    cycleNullRunAtMax
    cycleSynthesizedAtMax
    cycleRework
)

type cycleOutcome struct {
    Decision      cycleDecision
    Report        *reviewparse.Report
    TurnsUsed     int
    ReviewerLimit int
    Metadata      map[string]string  // ErrorCategory, ErrorSubcategory propagation
}

func runOneCycle(ctx context.Context, req *proto.StageRequestV1, budget *reviewparse.CycleBudget, bumpedLimit int) (*cycleOutcome, error) {
    // 1. Assemble context — bash lines 46-96.
    //    - Architecture cache via _get_cached_architecture_content (audit for Go equivalent first).
    //    - Repo-map slice via run_repo_map / get_repo_map_slice — call internal/indexer if Go-native; else exec tekhton subcommand.
    //    - MILESTONE_BLOCK focus via set_focused_milestone_block.
    //    - PRIOR_BLOCKERS_BLOCK toggle when budget.Current > 1.
    assembleReviewContext(ctx, req, budget)

    // 2. Render reviewer prompt — bash line 109.
    prompt, err := renderPrompt(ctx, req, "reviewer", promptVars{
        ReviewCycle:           budget.Current,
        MaxReviewCycles:       budget.Max,
        PriorBlockersBlock:    budget.Current > 1,
        // ... other prompt vars
    })
    if err != nil { return nil, err }

    // 3. Invoke reviewer agent — bash lines 114-126.
    limit := bumpedLimit
    if limit == 0 { limit = adjustedReviewerTurns(req) }
    agentRes, err := invokeAgent(ctx, req, agentInvocation{
        Label:    fmt.Sprintf("Reviewer (cycle %d)", budget.Current),
        Model:    reviewerModel(req),
        MaxTurns: limit,
        Prompt:   prompt,
        Tools:    req.Metadata["agent_tools_reviewer"],
    })
    if err != nil { return nil, err }

    // 4. Handle upstream / null-run / no-report fallbacks.
    if agentRes.ErrorCategory == "UPSTREAM" {
        if budget.IsExhausted() {
            return &cycleOutcome{
                Decision: cycleUpstreamErrorAtMax,
                Metadata: map[string]string{
                    "agent_error_subcategory": agentRes.ErrorSubcategory,
                    "agent_error_message":     agentRes.ErrorMessage,
                },
            }, nil
        }
        return &cycleOutcome{Decision: cycleRework, TurnsUsed: agentRes.TurnsUsed, ReviewerLimit: limit}, nil
    }
    if agentRes.NullRun {
        if budget.IsExhausted() {
            return &cycleOutcome{Decision: cycleNullRunAtMax}, nil
        }
        return &cycleOutcome{Decision: cycleRework, TurnsUsed: agentRes.TurnsUsed, ReviewerLimit: limit}, nil
    }
    reportPath := reviewerReportPath(req)
    if !fileExists(reportPath) {
        if !budget.IsExhausted() {
            return &cycleOutcome{Decision: cycleRework, TurnsUsed: agentRes.TurnsUsed, ReviewerLimit: limit}, nil
        }
        // bash lines 192-213 — synthesize-at-max.
        if err := synthesizeMinimalReport(reportPath); err != nil { return nil, err }
        if err := tripCommitGate(ctx, req, "reviewer_did_not_produce_report"); err != nil { return nil, err }
        return &cycleOutcome{Decision: cycleSynthesizedAtMax}, nil
    }

    // 5. Parse the report via internal/review.
    report, err := reviewparse.ParseReviewerReport(reportPath)
    if err != nil { return nil, fmt.Errorf("cycle %d: parse report: %w", budget.Current, err) }

    // 6. REPLAN_REQUIRED branch — bash lines 228-237.
    if report.Verdict == reviewparse.VerdictReplanRequired {
        decision, err := triggerReplan(ctx, req, reportPath)
        if err != nil { return nil, err }
        switch decision {
        case replanUserAborted:
            return &cycleOutcome{Decision: cycleReplanAbort}, nil
        case replanContinue:
            return &cycleOutcome{Decision: cycleReplanContinue}, nil
        }
    }

    // 7. APPROVED / APPROVED_WITH_NOTES — bash lines 224-226.
    if report.IsApproved() {
        return &cycleOutcome{Decision: cycleAccept, Report: report, TurnsUsed: agentRes.TurnsUsed, ReviewerLimit: limit}, nil
    }

    // 8. CHANGES_REQUIRED at the last cycle → blockers_remain (caller handles).
    if budget.IsExhausted() && (report.HasComplexBlockers() > 0 || report.HasSimpleBlockers() > 0) {
        return &cycleOutcome{Decision: cycleRework, Report: report, TurnsUsed: agentRes.TurnsUsed, ReviewerLimit: limit}, nil
        // RunStage's loop will exit here; blockersRemainResult is built after the loop.
    }

    // 9. CHANGES_REQUIRED with cycles remaining → rework.
    return &cycleOutcome{Decision: cycleRework, Report: report, TurnsUsed: agentRes.TurnsUsed, ReviewerLimit: limit}, nil
}
```

### Goal 3 — `runRework` — senior / jr / both matrix

```go
// internal/stages/review/rework.go
package review

func runRework(ctx context.Context, req *proto.StageRequestV1, report *reviewparse.Report, budget reviewparse.CycleBudget) error {
    hasComplex := report.HasComplexBlockers()
    hasSimple := report.HasSimpleBlockers()

    if hasComplex > 0 {
        // Senior coder rework — bash lines 273-293. Renders coder_rework.prompt.md.
        if err := invokeCoderRework(ctx, req, budget, "senior"); err != nil { return err }
        if hasSimple > 0 {
            // Jr coder follow-up — bash lines 294-312. JR_AFTER_SENIOR=yes flag.
            if err := invokeJrCoderRework(ctx, req, budget, true /* afterSenior */); err != nil { return err }
        }
    } else if hasSimple > 0 {
        // Jr coder only — bash lines 314-334. JR_AFTER_SENIOR="" (unset).
        if err := invokeJrCoderRework(ctx, req, budget, false); err != nil { return err }
    }

    // Build gate + escalation — bash lines 335-352.
    if err := runBuildGate(ctx, req, "post-fix-pass"); err != nil {
        // Escalate via build_fix_minimal coder pass.
        if err := invokeBuildFixMinimal(ctx, req); err != nil {
            return fmt.Errorf("build_fix_minimal escalation: %w", err)
        }
        if err := runBuildGate(ctx, req, "post-fix-pass-retry"); err != nil {
            return fmt.Errorf("build_failure_after_retry: %w", err)
        }
    }
    return nil
}

// invokeCoderRework renders coder_rework.prompt.md (NOT coder.prompt.md — see
// m37 parent Watch For) and invokes the senior-coder model. Mirrors bash
// lines 275-289.
func invokeCoderRework(ctx context.Context, req *proto.StageRequestV1, budget reviewparse.CycleBudget, role string) error {
    prompt, err := renderPrompt(ctx, req, "coder_rework", promptVars{ReviewCycle: budget.Current})
    if err != nil { return err }
    _, err = invokeAgent(ctx, req, agentInvocation{
        Label:    fmt.Sprintf("Coder (rework cycle %d)", budget.Current),
        Model:    coderModel(req),
        MaxTurns: effectiveCoderMaxTurns(req),
        Prompt:   prompt,
        Tools:    req.Metadata["agent_tools_coder"],
    })
    return err
}

func invokeJrCoderRework(ctx context.Context, req *proto.StageRequestV1, budget reviewparse.CycleBudget, afterSenior bool) error {
    vars := promptVars{ReviewCycle: budget.Current}
    if afterSenior { vars.JrAfterSenior = "yes" }
    prompt, err := renderPrompt(ctx, req, "jr_coder", vars)
    if err != nil { return err }
    _, err = invokeAgent(ctx, req, agentInvocation{
        Label:    fmt.Sprintf("Jr Coder (cycle %d)", budget.Current),
        Model:    jrCoderModel(req),
        MaxTurns: effectiveJrCoderMaxTurns(req),
        Prompt:   prompt,
        Tools:    req.Metadata["agent_tools_jr_coder"],
    })
    return err
}
```

### Goal 4 — Skip heuristics

```go
// internal/stages/review/skip.go
package review

func shouldSkipPolish(req *proto.StageRequestV1) bool {
    // Calls the existing Go-side polish detector if available (audit internal/detect),
    // otherwise exec `tekhton detect polish-mode`. The bash function
    // should_skip_review_for_polish is the reference (lives in lib/, audit on entry).
    // Returns true iff all changed files are non-logic.
}

type sizeSkipReason struct {
    Threshold string
    DiffLines string
}

func shouldSkipBySize(req *proto.StageRequestV1) (sizeSkipReason, bool) {
    // bash lines 27-36 — REVIEW_SKIP_THRESHOLD env-driven, default 0 (disabled).
    // Skip iff:
    //   - threshold > 0
    //   - MILESTONE_MODE != "true" (read from req.Metadata["milestone_mode"])
    //   - git diff --stat HEAD insertions+deletions < threshold
    threshold := atoi(req.Metadata["review_skip_threshold"])
    if threshold == 0 { return sizeSkipReason{}, false }
    if req.Metadata["milestone_mode"] == "true" { return sizeSkipReason{}, false }
    diffLines, err := gitDiffStatTotal(ctx, req.ProjectDir)
    if err != nil || diffLines == 0 { return sizeSkipReason{}, false }
    if diffLines >= threshold { return sizeSkipReason{}, false }
    return sizeSkipReason{
        Threshold: strconv.Itoa(threshold),
        DiffLines: strconv.Itoa(diffLines),
    }, true
}
```

### Goal 5 — Specialist post-loop branch

```go
// internal/stages/review/specialist.go
package review

import reviewparse "github.com/geoffgodwin/tekhton/internal/review"

func finalizeApproved(ctx context.Context, req *proto.StageRequestV1, report *reviewparse.Report, budget reviewparse.CycleBudget) (*proto.StageResultV1, error) {
    // bash lines 373-377 — run specialist reviews, route specialist rework on blockers.
    specialistBlockers, err := runSpecialistReviews(ctx, req)
    if err != nil { return nil, err }

    decision := reviewparse.RouteSpecialistRework(specialistBlockers, budget)
    switch decision {
    case reviewparse.SpecialistPassthrough:
        return approvedResult(req, report, budget), nil
    case reviewparse.SpecialistExhausted:
        return failResult(req, "specialist_blockers", budget, map[string]string{
            "specialist_report_file": specialistReportFile(req),
        }), nil
    case reviewparse.SpecialistRework:
        // Append specialist section to reviewer report.
        section := reviewparse.FormatSpecialistSection(specialistBlockers)
        if err := appendToFile(reviewerReportPath(req), section); err != nil { return nil, err }
        // Invoke senior coder rework + build gate + new reviewer pass.
        budget.Increment()
        if err := invokeCoderRework(ctx, req, budget, "senior"); err != nil { return nil, err }
        if err := runBuildGateWithEscalation(ctx, req, "post-specialist-rework", "post-specialist-retry"); err != nil {
            return failResult(req, "specialist_build_failure", budget, nil), nil
        }
        // Re-run reviewer pass — bash lines 61-77 of review_helpers.sh.
        cycleOut, err := runOneCycle(ctx, req, &budget, 0)
        if err != nil { return nil, err }
        if cycleOut.Report != nil && cycleOut.Report.IsApproved() {
            return approvedResult(req, cycleOut.Report, budget), nil
        }
        // Specialist rework reviewer didn't approve → blockers remain.
        return blockersRemainResult(req, cycleOut.Report, budget), nil
    }
    return nil, fmt.Errorf("review: unreachable specialist decision %v", decision)
}
```

### Goal 8 — Parity fixture set

## Watch For

- **`MAX_REVIEW_CYCLES` must be respected exactly as today.** Both the `for budget.Current < budget.Max` loop bound AND the in-loop `IsExhausted()` checks (synthesize-at-max trigger, upstream-error-at-max, null-run-at-max) consult the same value. A fixture with `Max=3` MUST produce exactly 3 reviewer invocations on the all-CHANGES_REQUIRED path. Off-by-one here is a regression operators will notice immediately (the M48 budget conversations were public).
- **The NEEDS_REWORK → coder routing path triggers `coder_rework.prompt.md`, NOT `coder.prompt.md`.** Initial coder uses `coder.prompt.md`; review-routed rework uses `coder_rework.prompt.md` (review.sh lines 275 and review_helpers.sh line 29). The two prompts have different role guidance — rework knows about the prior reviewer report; initial coder does not. `rework.go::invokeCoderRework` MUST pass template name `"coder_rework"` to `renderPrompt`. A unit test asserts the template name explicitly.
- **`REVIEWER_REPORT.md` format byte-for-byte preservation.** The metrics subsystem (`internal/metrics/`) parses this file. Every section heading, every "None" sentinel, every verdict token is operator vocabulary. The synthesize-at-max template (review.sh lines 194-211) is reproduced byte-for-byte by `synthesizeMinimalReport` — capture the bash output into `internal/stages/review/testdata/fixtures_v4/synthesized-at-max/expected_reviewer_report.md` BEFORE deleting the bash file, and assert byte-for-byte equality.
- **The review stage does NOT mutate state files directly.** Every `write_pipeline_state` call in the bash version (lines 156, 171, 347, 360, plus 23 in review_helpers.sh) becomes a `StageResultV1` field (`Verdict` + `ExitReason` + `Metadata`). The runner reads the envelope and persists via `internal/state/`. Any `os.WriteFile` to `PIPELINE_STATE.md` inside `internal/stages/review/` is a bug — `grep` for it during code review.
- **The fixture-capture step happens BEFORE the bash deletes.** Order is mandatory: capture six scenarios from bash output → commit fixtures → develop Go port → parity test passes → delete bash files. Deleting before capture means there's no truth for the synthesize-at-max template, and the byte-for-byte assertion has no reference. The implementer who tries to optimize this ordering will burn an entire dogfood cycle reconstructing the bash output.
- **The skip heuristics bypass the cycle loop AND skip the specialist branch.** Bash line 22 returns from `run_stage_review` immediately on polish skip; the specialist post-loop branch (line 373) never runs. The Go port matches: skip heuristics return from `RunStage` before `finalizeApproved` is called. A test that hits the polish-skip path asserts the specialist agent invoker is never called.
- **`_route_specialist_rework` cycle-counter increment.** Bash line 58 of review_helpers.sh increments `REVIEW_CYCLE` before the post-specialist reviewer pass — that "second-rework cycle" counts against the cycle budget. The Go port's `finalizeApproved::SpecialistRework` branch calls `budget.Increment()` before `runOneCycle`. If the budget is already at max when the specialist branch fires, the increment pushes it past max — but the bash code didn't check this; it always tried the rework. The Go port matches: increment unconditionally, let `runOneCycle` discover the exhaustion via its normal sentinel.
- **The `print_run_summary` M96 (IA1) suppression rule.** Bash calls `print_run_summary` once per reviewer cycle (line 127), suppresses after sub-agent completions (lines 290-292, 308-310, 331-332 commentary, 380-381 commentary). The Go port preserves the same suppression rule: `runOneCycle` calls `printRunSummary` once after the reviewer pass; `runRework` does NOT call it after each coder/jr-coder. A fixture with two cycles + one rework asserts exactly two summary lines in the captured stdout.
- **The cycle-loop placement decision is locked for M37.** Don't hoist into `internal/orchestrate/` mid-implementation. If the in-stage loop produces an awkward signature, open a Drift Observation and continue — the post-M39 refactor window is the right time, not mid-port. This was stated in the m37 parent and is restated here because it's the decision most likely to drift during implementation.
