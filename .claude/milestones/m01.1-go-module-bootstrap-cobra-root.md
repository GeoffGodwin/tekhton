#### Milestone 1.1: Go Module Bootstrap & Cobra Root

Stand up the Go module skeleton with a working Cobra root command and version injection. This sub-milestone produces a buildable `bin/tekhton` binary that prints its version, with no CI or self-host integration yet.

Files to create:
- `go.mod`
- `go.sum`
- `cmd/tekhton/main.go`
- `internal/version/version.go`
- `Makefile` (with `build`, `test`, `clean` targets only — `build-all` lands in 1.2)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23`.
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`.
- `bin/tekhton --help` produces standard Cobra output; bare invocation exits non-zero with help.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- Direct `go build` (without make) leaves `Version` at the `dev` sentinel.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Version comes from `-ldflags "-X"` injection, NOT `//go:embed` (embed cannot traverse out of source directory).
- CGO must stay disabled in the Makefile (`CGO_ENABLED=0`) — required for the static-binary promise.
- Trim trailing whitespace from the version string at print time.
- Pin `go 1.23` exactly in `go.mod`; drift causes CI flake later.

Seeds Forward:
- Milestone 1.2 depends on the Makefile structure to add `build-all` cross-compile target.
- Milestone 1.3 depends on `bin/tekhton --version` working for the self-host assertion.
