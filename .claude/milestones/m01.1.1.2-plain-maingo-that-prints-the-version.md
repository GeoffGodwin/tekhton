#### Milestone 1.1.1.2: Plain `main.go` That Prints the Version

Add a dependency-free `main` package under `cmd/tekhton` that imports `internal/version` and prints the `Version` variable to stdout. Build via plain `go build` only — Makefile and ldflags injection arrive in 1.1.1.3.

Files to create:
- `cmd/tekhton/main.go`

Acceptance criteria:
- `cmd/tekhton/main.go` declares `package main` with a `func main()` that writes `version.Version` followed by a newline to stdout and exits 0.
- Only standard-library imports plus `github.com/geoffgodwin/tekhton/internal/version` are used (no Cobra, no third-party deps).
- `go build -o /tmp/tekhton-smoke ./cmd/tekhton` succeeds and the resulting binary prints exactly `dev\n` when invoked with no arguments.
- `go vet ./cmd/tekhton` exits 0.
- `go.sum` is still absent (no new transitive deps).
- No `Makefile`, `bin/` directory, or other top-level artifact is created.

Watch For:
- Print should trim trailing whitespace from `version.Version` (e.g. `strings.TrimSpace`) so that the ldflags-injected value in 1.1.1.3 stays clean even if the `VERSION` file picks up a stray newline.
- Keep `main.go` minimal — no flag parsing, no `--version` handling, no Cobra scaffolding. Those land in Milestone 1.1.2.
- Do not write the version string with `fmt.Print` without a newline; the existing tests in 1.1.1.3 expect a single trailing newline.

Seeds Forward:
- Milestone 1.1.1.3 wraps this `go build` invocation in `make build` with `-ldflags "-X .../internal/version.Version=<VERSION-file-contents>"`.
- Milestone 1.1.2 replaces this plain `main` body with a Cobra root command while preserving the version-print contract.
