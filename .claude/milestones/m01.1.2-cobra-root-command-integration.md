#### Milestone 1.1.2: Cobra Root Command Integration

Replace the minimal `main.go` with a proper Cobra root command exposing `--version` and `--help` flags. This sub-milestone adds the Cobra dependency, generates `go.sum`, and finalizes the CLI surface promised by the parent milestone.

Files to modify:
- `cmd/tekhton/main.go` (rewrite to use Cobra)
- `go.mod` (add `github.com/spf13/cobra` dependency)

Files to create:
- `go.sum` (generated by `go mod tidy` after adding Cobra)

Acceptance criteria:
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION` (via the same ldflags-injected `version.Version` from 1.1.1).
- `bin/tekhton --help` produces standard Cobra output (usage line, flags section).
- Bare `bin/tekhton` invocation exits non-zero and prints help to stderr.
- Direct `go build ./cmd/tekhton` (without make) still leaves `Version` at the `dev` sentinel — `bin/tekhton --version` then prints `dev`.
- `make build` still succeeds and `bin/tekhton --version` prints the real version.
- `make test` still exits 0.
- `go.sum` is committed and `go mod verify` succeeds.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- The `Makefile` from 1.1.1 is unchanged (ldflags target string already references `internal/version.Version`).

Watch For:
- Use Cobra's built-in `--version` support (`rootCmd.Version = version.Version`) rather than rolling a custom flag — the auto-generated `--version` output is the canonical Cobra behavior.
- Configure `rootCmd.SilenceUsage = false` and rely on Cobra's default `RunE` returning an error on bare invocation, OR set `Args: cobra.NoArgs` with no `Run`/`RunE` so help prints and exit code is non-zero.
- Pick a single Cobra version (e.g. `v1.8.x`) compatible with `go 1.23`; let `go mod tidy` resolve the indirect deps into `go.sum`.
- Do NOT change the ldflags string in the Makefile — it must keep targeting `github.com/geoffgodwin/tekhton/internal/version.Version`.
- Preserve the `dev` sentinel default in `internal/version/version.go` so plain `go build` still works.

Seeds Forward:
- Milestone 1.2 inherits a working `bin/tekhton --version` for cross-platform smoke tests after `build-all`.
- Milestone 1.3 invokes `bin/tekhton --version` directly in self-host assertions; the exit code and output format established here are load-bearing.
- Future sub-commands (added in later milestones) attach to the `rootCmd` defined in `cmd/tekhton/main.go`.
