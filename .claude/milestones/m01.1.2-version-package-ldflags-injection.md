#### Milestone 1.1.2: Version Package + ldflags Injection
Add the `internal/version` package and wire `-ldflags "-X"` injection through the Makefile. The binary now prints the trimmed contents of repo-root `VERSION` when built via `make`, but falls back to a `dev` sentinel under direct `go build`.

Files to create:
- `internal/version/version.go` (exports `Version` variable defaulting to `"dev"`)

Files to modify:
- `cmd/tekhton/main.go` (print `version.Version` trimmed of trailing whitespace)
- `Makefile` (add `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION)"` to `build` target)

Acceptance criteria:
- `internal/version/version.go` declares `package version` and exports `var Version = "dev"`.
- `make build && ./bin/tekhton` prints the trimmed contents of repo-root `VERSION`.
- Direct `go build -o bin/tekhton ./cmd/tekhton` (without make) produces a binary that prints `dev`.
- Trailing whitespace/newlines from `VERSION` are trimmed at print time (use `strings.TrimSpace`).
- `make test` still exits 0.
- No Cobra dependency added yet; `go.sum` remains empty.

Watch For:
- Version comes from `-ldflags "-X"` injection, NOT `//go:embed` (embed cannot traverse out of source directory to reach repo-root `VERSION`).
- The ldflags `-X` path must match the full import path of the `Version` variable exactly: `github.com/geoffgodwin/tekhton/internal/version.Version`.
- Trim at print time, not in the ldflags value — `$(shell cat VERSION)` may include a trailing newline.

Seeds Forward:
- Milestone 1.1.3 depends on `version.Version` being importable so the Cobra `--version` flag can surface it.
