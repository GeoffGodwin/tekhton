#### Milestone 1.1.2: Wire VERSION File Injection via ldflags

Modify the Makefile to inject the trimmed contents of repo-root `VERSION` into the `internal/version.Version` symbol at build time. After this sub-milestone, `make build` produces a binary that prints the real version, while a direct `go build` invocation still leaves the `dev` sentinel intact.

Files to modify:
- `Makefile` (extend `build` target with `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=<trimmed VERSION>"`)
- `internal/version/version.go` (ensure `Get()` trims trailing whitespace defensively)

Acceptance criteria:
- `bin/tekhton --version` (after `make build`) prints the trimmed contents of repo-root `VERSION`.
- Direct `go build -o /tmp/tekhton-direct ./cmd/tekhton && /tmp/tekhton-direct --version` prints `dev`.
- `make build` succeeds even if `VERSION` ends with a trailing newline (output is trimmed).
- `make test` still exits 0.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- No new files created in this sub-milestone — only Makefile and version.go are touched.

Watch For:
- Use `-ldflags "-X"` injection, NOT `//go:embed` — embed cannot traverse out of `internal/version/` to reach the repo-root `VERSION` file.
- Trim trailing whitespace from the VERSION string in the Makefile shell substitution (`$(shell cat VERSION | tr -d '[:space:]')`) AND defensively in `Get()` at print time.
- The `-X` path must match the full module path exactly: `github.com/geoffgodwin/tekhton/internal/version.Version`.
- Keep `CGO_ENABLED=0` on the build line — ldflags additions must not drop it.

Seeds Forward:
- Milestone 1.2 depends on the ldflags pattern being established before adding `build-all` for cross-compile (each GOOS/GOARCH target needs the same `-X` injection).
- Milestone 1.3 depends on `bin/tekhton --version` printing real VERSION contents for the self-host assertion.
