# m35.1 — Security Helpers Port

## Overview

| Item | Detail |
|------|--------|
| **Arc motivation** | First child porting the security subsystem (m35 parent). Lands the Go-native helpers package + bash shim that lets the bash stage (`stages/security.sh`) continue to work unchanged while the underlying severity classification, finding parsing, and escalation logic move to Go. After m35.1, every helper-function call from the bash stage execs into the Go binary — the bash logic in `lib/security_helpers.sh` shrinks from 240 LOC to a ~40-LOC shim. The bash stage stays operationally green through the transition so a dogfooded `tekhton run --milestone m35.1 --complete` cycle exercises the new Go path end-to-end without requiring M35.2's RunStage to ship first. |
| **Gap** | `lib/security_helpers.sh` (240 LOC) is bash-native logic that runs on every non-docs-only pipeline. ## Design

### Sequencing note

m35.1 lands before m35.2 because the helpers are what the stage calls. Porting helpers first means M35.2 starts with a tested Go API instead of inventing one alongside the stage port. The bash shim keeps the bash stage green during M35.1 → M35.2 — the stage doesn't notice the helpers moved. The dogfooded m35.1 cycle exercises the Go helpers via the still-bash stage, which is the cheapest way to surface integration bugs before M35.2 commits to deleting the bash stage.

### Goal 1 — `severity.go`

```go
package security

type Severity string

const (
    SeverityCritical Severity = "CRITICAL"
    SeverityHigh     Severity = "HIGH"
    SeverityMedium   Severity = "MEDIUM"
    SeverityLow      Severity = "LOW"
)

// severityRank mirrors the bash associative array at lib/security_helpers.sh:118.
// Unknown severities map to 0 — matches the bash `:-0` fallback.
var severityRank = map[Severity]int{
    SeverityCritical: 4,
    SeverityHigh:     3,
    SeverityMedium:   2,
    SeverityLow:      1,
}

// Rank returns the ordering value. Unknown returns 0.
func Rank(s Severity) int { return severityRank[s] }

// MeetsThreshold reports whether s is at least threshold. Mirrors
// _severity_meets_threshold: `[[ "$sev_val" -ge "$thr_val" ]]`. Unknown values
// rank as 0, so unknown threshold is met by any LOW-or-better; unknown severity
// fails any LOW-or-stricter threshold.
func MeetsThreshold(s, threshold Severity) bool {
    return Rank(s) >= Rank(threshold)
}
```

Test table covers: all 16 (severity × threshold) pairs from {CRITICAL, HIGH, MEDIUM, LOW}, plus 8 with one or both sides set to "" (the unknown case), plus 4 with mixed-case input ("high" vs "HIGH" — bash is case-sensitive, the Go port preserves this).

### Goal 2 — `findings.go`

```go
package security

import (
    "bufio"
    "os"
    "path/filepath"
    "regexp"
    "strings"
)

type Finding struct {
    Severity    Severity
    Fixable     string  // "yes" | "no" | "unknown"
    Description string
}

// severityRE matches the [SEVERITY] token in a finding row.
var severityRE = regexp.MustCompile(`\[(CRITICAL|HIGH|MEDIUM|LOW)\]`)

// fixableRE matches the fixable:VALUE token.
var fixableRE = regexp.MustCompile(`fixable:(yes|no|unknown)`)

// ParseReport scans path for the `## Findings` section and returns each
// `- [SEV] [fixable:V] desc` row as a Finding. Returns (nil, nil) when path
// doesn't exist — matches the bash semantics that a missing report means
// "no findings, proceed".
func ParseReport(path string) ([]Finding, error) {
    f, err := os.Open(path)
    if os.IsNotExist(err) {
        return nil, nil
    }
    if err != nil {
        return nil, err
    }
    defer f.Close()

    var out []Finding
    in := false
    sc := bufio.NewScanner(f)
    for sc.Scan() {
        line := sc.Text()
        // Enter findings section.
        if strings.HasPrefix(line, "## Findings") {
            in = true
            continue
        }
        // Exit on the next `## ` header.
        if in && strings.HasPrefix(line, "## ") {
            break
        }
        if !in || !strings.HasPrefix(line, "- ") {
            continue
        }
        sevMatch := severityRE.FindStringSubmatch(line)
        if len(sevMatch) < 2 {
            continue  // row without a severity → bash also skips it
        }
        fix := "unknown"
        if m := fixableRE.FindStringSubmatch(line); len(m) >= 2 {
            fix = m[1]
        }
        // Description is everything after the last `] ` — matches bash `${line#*] }`.
        desc := line
        if i := strings.Index(line, "] "); i >= 0 {
            desc = line[i+2:]
        }
        out = append(out, Finding{
            Severity:    Severity(sevMatch[1]),
            Fixable:     fix,
            Description: desc,
        })
    }
    return out, sc.Err()
}

// docsExt is the allowlist that lets a file count as "not code" for the
// fast-path skip. Mirrors lib/security_helpers.sh:43-48 verbatim.
var docsExt = map[string]bool{
    "md": true, "txt": true, "rst": true, "csv": true,
    "json": true, "yaml": true, "yml": true, "toml": true, "cfg": true,
    "png": true, "jpg": true, "jpeg": true, "gif": true, "svg": true,
    "ico": true, "woff": true, "woff2": true, "ttf": true, "eot": true,
}

// IsDocsOnly reports whether every file extracted from the coder summary is in
// docsExt. Returns (false, nil) when the summary file is missing — bash returns
// 1 in this case, which is "scan anyway".
func IsDocsOnly(summaryPath string) (bool, error) {
    files, err := readChangedFiles(summaryPath)
    if err != nil {
        return false, err
    }
    if files == nil {
        return false, nil  // summary missing → scan anyway
    }
    if len(files) == 0 {
        return true, nil   // empty file list → skip (matches bash)
    }
    for _, f := range files {
        ext := strings.TrimPrefix(filepath.Ext(f), ".")
        if !docsExt[ext] {
            return false, nil
        }
    }
    return true, nil
}

// readChangedFiles mirrors agent_helpers.sh::extract_files_from_coder_summary.
// The Go runtime should already have this in internal/coder_summary or similar
// (m34 should have introduced it). If not, M35.1 adds a thin wrapper.
func readChangedFiles(summaryPath string) ([]string, error) { /* … */ }
```

`readChangedFiles` reads the `## Files created or modified` section of `CODER_SUMMARY.md`. If M34 introduced a shared helper, reuse it; otherwise M35.1 ports the bash `extract_files_from_coder_summary` inline (it's a small awk-ish scan).

### Goal 3 — `blocks.go`

```go
package security

import "strings"

// BuildFixableBlock returns findings >= threshold AND fixable == "yes" as a
// newline-joined `- [SEV] desc\n` list. Trailing newline preserved (bash builds
// the result with `result+="...\n"` and echoes it). Empty when no matches.
func BuildFixableBlock(fs []Finding, threshold Severity) string {
    var b strings.Builder
    for _, f := range fs {
        if MeetsThreshold(f.Severity, threshold) && f.Fixable == "yes" {
            b.WriteString("- [")
            b.WriteString(string(f.Severity))
            b.WriteString("] ")
            b.WriteString(f.Description)
            b.WriteByte('\n')
        }
    }
    return b.String()
}
```

### Goal 4 — `escalation.go`

```go
package security

import (
    "fmt"
    "github.com/geoffgodwin/tekhton/internal/drift"
    "github.com/geoffgodwin/tekhton/internal/state"
)

// Escalator owns the seams onto the escalation targets: the HUMAN_ACTION file
// (drift package, m25) and the state store (for the halt branch).
type Escalator struct {
    HumanAction *drift.HumanAction
    State       *state.Store
}

// NewEscalator returns an Escalator bound to projectDir's HUMAN_ACTION_REQUIRED.md.
// state may be nil for callers that don't exercise the halt branch.
func NewEscalator(projectDir string, st *state.Store) *Escalator {
    haPath := filepath.Join(projectDir, ".tekhton", "HUMAN_ACTION_REQUIRED.md")
    return &Escalator{HumanAction: drift.NewHumanAction(haPath), State: st}
}

// HandleUnfixable applies SECURITY_UNFIXABLE_POLICY to the unfixable findings
// block. Returns (true, nil) for "continue pipeline" branches (escalate,
// waiver, unknown→default-escalate). Returns (false, nil) for halt — the
// caller must propagate this as a block verdict and stop the pipeline.
//
// Mirrors lib/security_helpers.sh::_handle_unfixable_findings.
func (e *Escalator) HandleUnfixable(policy, unfixableBlock, task string) (bool, error) {
    if unfixableBlock == "" {
        return true, nil  // matches bash short-circuit at line 181
    }
    desc := "Unfixable security findings require human review:\n" + unfixableBlock
    switch policy {
    case "escalate", "":
        return true, e.appendHumanAction(desc)
    case "halt":
        // m35.1 returns (false, nil) — caller is responsible for the write_pipeline_state
        // and the error log. M35.2's RunStage owns the state-write because that's the
        // stage's responsibility, not a helper's.
        return false, nil
    case "waiver":
        return true, nil  // log line is emitted by RunStage, not here
    default:
        // Unknown policy defaults to escalate (matches bash line 207-216).
        return true, e.appendHumanAction("Unfixable security findings:\n" + unfixableBlock)
    }
}

func (e *Escalator) appendHumanAction(desc string) error {
    if err := e.HumanAction.EnsureFile(); err != nil {
        return fmt.Errorf("security escalation: ensure human-action file: %w", err)
    }
    if err := e.HumanAction.Append("security", desc); err != nil {
        return fmt.Errorf("security escalation: append: %w", err)
    }
    return nil
}
```

The four branches map 1:1 to the bash case statement at line 184-216. The "unknown defaults to escalate" branch must also include the warning log — but the log emit is the stage's responsibility (M35.2), not the helper's. The helper just routes.

### Goal 5 — `cmd/tekhton/security.go` (CLI shim backing)

```go
package main

import "github.com/spf13/cobra"

func newSecurityCmd() *cobra.Command {
    cmd := &cobra.Command{Use: "security", Short: "Security helpers", Hidden: true}
    cmd.AddCommand(
        newSecurityParseFindingsCmd(),
        newSecurityMeetsThresholdCmd(),
        newSecurityBuildBlockCmd(),
        newSecurityIsDocsOnlyCmd(),
        newSecurityHandleUnfixableCmd(),
    )
    return cmd
}

func newSecurityParseFindingsCmd() *cobra.Command {
    var report, format string
    return &cobra.Command{
        Use: "parse-findings",
        RunE: func(cmd *cobra.Command, _ []string) error {
            fs, err := security.ParseReport(report)
            if err != nil { return err }
            switch format {
            case "tsv":
                for _, f := range fs {
                    fmt.Fprintf(cmd.OutOrStdout(), "%s\t%s\t%s\n", f.Severity, f.Fixable, f.Description)
                }
            case "json":
                return json.NewEncoder(cmd.OutOrStdout()).Encode(fs)
            }
            return nil
        },
    }
}

// ... meets-threshold, build-block, is-docs-only, handle-unfixable analogous.
```

The TSV format is parity-stable: 3 tab-separated columns (severity, fixable, description). The bash shim reads it back into the legacy `_SEC_SEVERITIES` / `_SEC_FIXABLES` / `_SEC_DESCRIPTIONS` arrays without modification.

`meets-threshold` exits 0 when the predicate is true, 1 when false — matches bash return-code semantics so the shim can use `if _severity_meets_threshold ...; then`.

### Goal 6 — `lib/security_helpers.sh` shim rewrite

Reduce 240 LOC to ~40 LOC:

```bash
#!/usr/bin/env bash
# lib/security_helpers.sh — M35.1 shim. Backs the bash stage with Go helpers.
# All logic lives in internal/security/. This file goes away in M35.2.

_security_is_docs_only() {
    "${TEKHTON_BIN:-tekhton}" security is-docs-only \
        --summary "${CODER_SUMMARY_FILE:-.tekhton/CODER_SUMMARY.md}"
}

_parse_security_findings() {
    local report_file="${1:-${SECURITY_REPORT_FILE:-.tekhton/SECURITY_REPORT.md}}"
    _SEC_SEVERITIES=() _SEC_FIXABLES=() _SEC_DESCRIPTIONS=()
    while IFS=$'\t' read -r sev fix desc; do
        [[ -z "$sev" ]] && continue
        _SEC_SEVERITIES+=("$sev")
        _SEC_FIXABLES+=("$fix")
        _SEC_DESCRIPTIONS+=("$desc")
    done < <("${TEKHTON_BIN:-tekhton}" security parse-findings --report "$report_file" --format tsv 2>/dev/null)
    [[ ${#_SEC_SEVERITIES[@]} -gt 0 ]]
}

_has_blocking_findings() {
    local block_severity="${SECURITY_BLOCK_SEVERITY:-HIGH}" i
    for i in "${!_SEC_SEVERITIES[@]}"; do
        if _severity_meets_threshold "${_SEC_SEVERITIES[$i]}" "$block_severity"; then
            return 0
        fi
    done
    return 1
}

_severity_meets_threshold() {
    "${TEKHTON_BIN:-tekhton}" security meets-threshold --severity "$1" --threshold "$2"
}

_build_fixable_block()   { _build_block fixable   "${SECURITY_BLOCK_SEVERITY:-HIGH}"; }
_build_unfixable_block() { _build_block unfixable "${SECURITY_BLOCK_SEVERITY:-HIGH}"; }
_build_notes_block()     { _build_block notes     "${SECURITY_BLOCK_SEVERITY:-HIGH}"; }

_build_block() {
    "${TEKHTON_BIN:-tekhton}" security build-block \
        --report "${SECURITY_REPORT_FILE:-.tekhton/SECURITY_REPORT.md}" \
        --kind "$1" --threshold "$2"
}

_handle_unfixable_findings() {
    "${TEKHTON_BIN:-tekhton}" security handle-unfixable \
        --policy "${SECURITY_UNFIXABLE_POLICY:-escalate}" \
        --block "$1" \
        --task "${TASK:-}" \
        --project-dir "${PROJECT_DIR:-$PWD}"
}

_write_security_notes() {
    # M35.1 keeps this in bash because it's a simple heredoc + only the
    # bash stage calls it. M35.2 ports it to internal/stages/security/.
    local notes_block="$1" unfixable_block="$2"
    local notes_file="${SECURITY_NOTES_FILE:-}"
    [[ -z "$notes_file" ]] && return 0
    {
        echo "# Security Notes"; echo
        echo "Generated: $(date '+%Y-%m-%d %H:%M:%S')"; echo
        if [[ -n "$notes_block" ]]; then
            echo "## Non-Blocking Findings (MEDIUM/LOW)"
            echo "$notes_block"
        fi
        if [[ -n "$unfixable_block" ]] && [[ "${SECURITY_UNFIXABLE_POLICY:-escalate}" == "waiver" ]]; then
            echo "## Waivered Findings"
            echo "$unfixable_block"
        fi
    } > "$notes_file"
}
```

`_write_security_notes` stays bash in M35.1 because the only caller is the bash stage. M35.2 ports it (a `WriteNotesFile(...)` Go function) when the stage moves Go-native.

## Watch For

- **Severity-classification thresholds must match bash byte-for-byte.** `CRITICAL=4, HIGH=3, MEDIUM=2, LOW=1, unknown=0`. The unknown-fallback is the trickiest case — bash returns 0 from `${severity_rank[$severity]:-0}`, and an unknown severity therefore fails any threshold from LOW upward. Do NOT refactor the ranking into a switch statement that would default unknown to MaxInt or similar; the Go map-lookup with zero-value fallback exactly mirrors bash.
- **`SECURITY_AGENT_ENABLED=false` is M35.2's responsibility, not M35.1's.** The kill-switch lives in the stage entrypoint, not the helpers. M35.1's helpers operate on whatever input they receive — they don't check feature flags. Adding the check here would duplicate logic the stage already needs.
- **The prompt template path stays the same — no template content changes.** M35.1 doesn't touch `prompts/security_scan.prompt.md`, `prompts/security_rework.prompt.md`, or `prompts/specialist_security.prompt.md`. The helpers don't render prompts; that's the stage's job.
- **HUMAN_ACTION_REQUIRED.md escalation MUST use `internal/drift/artifacts.go::HumanAction.Append`.** The `Escalator` type wraps `*drift.HumanAction` precisely so this routing is enforced. Do not call `os.WriteFile` or `os.OpenFile` from `escalation.go` — every write goes through the drift package. The m25 design said drift is the universal writer; M35 inherits that constraint.
- **The shim's TSV format is a contract.** Three tab-separated columns: severity, fixable, description. If a description ever contains a tab (unlikely but possible), the parser will mis-split. Add a TSV-escape pass if a finding fixture surfaces this — but the bash version had the same vulnerability, so M35.1 preserves the existing behavior and documents the edge case in `cmd/tekhton/security.go` comments.
- **`_write_security_notes` stays in bash for M35.1.** Only the bash stage calls it. M35.2 ports it. Do not preemptively port it in M35.1 — that's scope creep, and the M35.2 RunStage needs to own the file-write path because it's stage-level state.
- **The `Escalator.HandleUnfixable` halt branch does NOT write pipeline state.** The bash version's halt branch (`lib/security_helpers.sh:194-202`) calls `write_pipeline_state` directly from the helper. M35.1 moves that responsibility to the stage (M35.2) because pipeline state is stage-owned. The M35.1 halt branch returns `(false, nil)` and lets the caller (M35.2's RunStage) write state with the correct stage-level context. If you're tempted to write state inline here, stop — it tangles the layering.
- **`SECURITY_UNFIXABLE_POLICY` defaults to `escalate`, NOT `halt`.** The bash default is `escalate`. The M35.1 switch statement's `case "escalate", "":` branch handles the unset case. An implementer who reads the halt branch first might assume halt is default — it is not.
- **The "unknown policy" branch's description prefix differs from the escalate branch.** Bash escalate: `"Unfixable security findings require human review:\n"`. Bash unknown-default: `"Unfixable security findings:\n"` (no "require human review"). This is operator-visible — the human-action file rows look different. Preserve both prefixes exactly.
