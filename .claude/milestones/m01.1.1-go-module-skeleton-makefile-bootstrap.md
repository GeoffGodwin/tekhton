#### Milestone 1.1.1: Go Module Skeleton & Makefile Bootstrap

Lay down the bare Go module with a minimal `main.go` stub and a Makefile that produces a runnable binary. No Cobra, no version injection yet — just proof that the toolchain, module path, and build pipeline work end-to-end.

Files to create:
- `go.mod`
- `cmd/tekhton/main.go` (minimal `package main` with empty `main()` or a single `fmt.Println`)
- `Makefile` (with `build`, `test`, `clean` targets — `CGO_ENABLED=0`)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23` pinned exactly.
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton` runs without panicking (output content not yet specified).
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes `bin/`.
- Makefile sets `CGO_ENABLED=0` for the build target.
- `.gitignore` ignores `bin/` and `*.test`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- `go.sum` may be absent at this stage (no dependencies yet).

Watch For:
- Pin `go 1.23` exactly in `go.mod`; drift causes CI flake later.
- CGO must stay disabled in the Makefile — required for the static-binary promise.
- Do NOT introduce Cobra yet; this milestone must compile with zero third-party deps so `go.sum` is not required to land.

Seeds Forward:
- Milestone 1.1.2 will add the Cobra dependency and replace the stub `main()` with a real root command — requires the `build` target's structure to remain stable.
- Milestone 1.1.3 will extend the Makefile with `-ldflags "-X"` injection — the `build` rule's recipe is the seam.
