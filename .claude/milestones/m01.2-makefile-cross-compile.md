#### Milestone 1.2: Makefile + Cross-Compile

Add the Makefile with local-build, test, cross-compile, and clean targets. CGO disabled everywhere to preserve the single-static-binary promise. Five-target matrix: `linux/amd64`, `linux/arm64`, `darwin/amd64`, `darwin/arm64`, `windows/amd64`.

Files to create:
- `Makefile` with targets:
  - `build`: `go build -trimpath -ldflags="-s -w -X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION)" -o bin/tekhton ./cmd/tekhton`
  - `test`: `go test ./...`
  - `build-all`: cross-compile to five OS/arch combos, output `bin/tekhton-<os>-<arch>[.exe]`, `CGO_ENABLED=0`
  - `clean`: `rm -rf bin/`

Acceptance criteria:
- `make build` on a clean checkout produces `bin/tekhton`; `bin/tekhton --version` prints the trimmed contents of `VERSION`.
- `make build-all` produces all five expected binaries; `file bin/tekhton-*` confirms each binary's target architecture.
- `make test` exits 0 with no test files yet (Go's "no tests to run" is acceptable).
- `make clean` removes `bin/` entirely.
- After `make build-all`, `git status` shows no `bin/` artifact (relies on m1.1's `.gitignore`).
- No CGO is invoked in any target.

Watch For:
- `darwin/*` cross-compiles cleanly only with CGO off — verify locally on Linux before relying on CI.
- Use `$(shell cat VERSION)` for portable command substitution; avoid bash-isms in Make recipes so the file works under both GNU make and BSD make.
- Don't add `make install` or other targets not listed — m01 ships only what's needed.

Seeds Forward:
- Milestone 1.3's CI workflow invokes `make build-all` and `make test` directly.
- Milestone 1.3's self-host check invokes `make build` before prepending `bin/` to `$PATH`.
