#### Milestone 1.1.1: Go Module Skeleton & Cobra Root Command

Stand up the Go module and a buildable Cobra root command with no version logic yet. This sub-milestone produces a `bin/tekhton` binary that responds to `--help` but does not yet support `--version`.

Files to create:
- `go.mod`
- `go.sum`
- `cmd/tekhton/main.go` (Cobra root command with help, no version flag)
- `Makefile` (with `build`, `test`, `clean` targets; no ldflags yet)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23` pinned exactly.
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton --help` produces standard Cobra output.
- Bare `bin/tekhton` invocation exits non-zero with help text.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes `bin/` directory.
- `CGO_ENABLED=0` is set in the Makefile build target.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Pin `go 1.23` exactly in `go.mod`; drift causes CI flake later.
- CGO must stay disabled in the Makefile (`CGO_ENABLED=0`) — required for the static-binary promise.
- Do not add a `--version` flag yet; that lands in 1.1.2.
- Use Cobra's standard `RunE` pattern so 1.1.2 can attach version output cleanly.

Seeds Forward:
- Milestone 1.1.2 depends on the Cobra root command structure to attach the `--version` flag.
- Milestone 1.1.2 depends on the Makefile `build` target to extend with `-ldflags` injection.
