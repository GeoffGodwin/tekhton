#### Milestone 1.1.3: Version Package & ldflags Injection

Introduce the `internal/version` package, wire `-ldflags "-X"` injection through the Makefile, and expose `bin/tekhton --version` reading from the repo-root `VERSION` file at build time.

Files to create:
- `internal/version/version.go` (exports a `Version` variable defaulting to `"dev"`)

Files to modify:
- `Makefile` (add `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION | tr -d '[:space:]')"` to the `build` target)
- `cmd/tekhton/main.go` (wire `--version` flag or `Version` field on the root Cobra command to print `version.Version`, trimming trailing whitespace at print time)

Acceptance criteria:
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`.
- Direct `go build ./cmd/tekhton` (without make) produces a binary whose `--version` reports `dev`.
- `make build` produces `bin/tekhton` with the injected version.
- `make test` exits 0.
- `bin/tekhton --help` still produces standard Cobra output.
- Bare `bin/tekhton` invocation still exits non-zero with help (regression check from 1.1.2).
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Version comes from `-ldflags "-X"` injection, NOT `//go:embed` (embed cannot traverse out of source directory to reach repo-root `VERSION`).
- Trim trailing whitespace from the version string at print time (newline at EOF of `VERSION` is the common foot-gun) — even though the Makefile also strips whitespace, the print-time trim guards against `dev` sentinel and manually-set values.
- The ldflags path must match the package import path exactly: `github.com/geoffgodwin/tekhton/internal/version.Version`.
- Do not export anything from `internal/version` beyond `Version` — keep the surface minimal.

Seeds Forward:
- Milestone 1.2 depends on the Makefile structure to add `build-all` cross-compile target — the ldflags string must be reused, so consider extracting it to a `LDFLAGS` variable in this milestone to ease 1.2.
- Milestone 1.3 depends on `bin/tekhton --version` working for the self-host assertion.
