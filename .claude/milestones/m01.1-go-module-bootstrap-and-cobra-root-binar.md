#### Milestone 1.1: Go Module Bootstrap and Cobra Root Binary

Establish the Go module in-repo and ship a buildable Cobra root command with `--version` wired through ldflags. After this sub-milestone, `make build` produces a working `bin/tekhton` binary locally, but no CI or cross-compilation exists yet.

Files to create:
- `go.mod`
- `go.sum`
- `cmd/tekhton/main.go`
- `internal/version/version.go`
- `Makefile` (with `build`, `test`, `clean` targets only)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module path `github.com/geoffgodwin/tekhton` and pins `go 1.23`.
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`.
- `bin/tekhton --help` produces standard Cobra help output.
- Direct `go build` (without make) leaves `Version` at the `dev` sentinel.
- `make test` exits 0 with Go's "no tests" output.
- `go vet ./...` is clean.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- `bash tests/run_tests.sh` produces identical output before and after.
- `bin/` does not appear in `git status` after `make build`.

Watch For:
- CGO must stay disabled — do not import any package that pulls in cgo.
- `//go:embed ../../VERSION` is invalid Go (embed cannot traverse out of the source directory). Use `-ldflags "-X"` injection instead.
- Trim trailing whitespace from the version string at print time.
- Only `cobra` should be added as a third-party dep; nothing else.

Seeds Forward:
- Milestone 1.2 adds `build-all` to the Makefile and depends on the binary layout established here.
- Milestone 1.3 depends on `bin/tekhton --version` being reachable for the self-host check.
