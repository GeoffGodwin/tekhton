#### Milestone 1.1.1.3: Makefile With Build / Test / Clean + ldflags Version Injection

Add the project `Makefile` that wires `go build` through `-ldflags "-X"` injection of the repo-root `VERSION` file contents, plus `test` and `clean` targets. Confirms the end-to-end story: `make build` → `bin/tekhton` → prints the trimmed `VERSION` file contents.

Files to create:
- `Makefile`

Acceptance criteria:
- `make build` on a clean checkout produces `bin/tekhton` and exits 0.
- `bin/tekhton` (bare invocation, no args) prints the trimmed contents of repo-root `VERSION` followed by a newline, then exits 0.
- `make test` exits 0 (Go's `?   ...    [no test files]` output is acceptable; do not add tests in this sub-milestone).
- `make clean` removes the `bin/` directory and exits 0 even if `bin/` is already absent.
- The build recipe sets `CGO_ENABLED=0` in the environment of the `go build` invocation.
- The `-ldflags` value uses `-X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION | tr -d '[:space:]')` (or equivalent shell-out that strips whitespace).
- Directly running `go build -o /tmp/tekhton-nomake ./cmd/tekhton` (without make) still produces a binary whose output is the `dev` sentinel — proving ldflags is the only injection path.
- Only `Makefile` is added; no changes under `cmd/`, `internal/`, `lib/`, `stages/`, `prompts/`, or `tools/`.
- No `go.sum` is created.

Watch For:
- Use tab indentation in the `Makefile`, not spaces — GNU make will fail with a cryptic "missing separator" error otherwise.
- The `$(shell cat VERSION | tr -d '[:space:]')` expansion happens at parse time; if `VERSION` is missing the build should fail loudly rather than inject an empty string — consider an explicit `$(if ...,$(error VERSION file missing))` guard.
- `make clean` must use `rm -rf bin/` (not `rm bin/tekhton`) so it succeeds when the binary was never built.
- Do NOT add a `build-all` cross-compile target here — that lands in Milestone 1.2.
- Quote the `-ldflags` argument as a single shell word so the `-X path=value` pair is not split by make's word splitting.

Seeds Forward:
- Milestone 1.1.2 extends this Makefile only by adding the Cobra dependency (no Makefile recipe changes expected).
- Milestone 1.2 adds a `build-all` target that reuses the same `-ldflags` expression across `GOOS`/`GOARCH` combinations.
