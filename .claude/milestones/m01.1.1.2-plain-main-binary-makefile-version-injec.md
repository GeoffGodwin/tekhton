#### Milestone 1.1.1.2: Plain Main Binary + Makefile + Version Injection

Layer the executable entry point and the build tooling on top of the module skeleton from 1.1.1.1. This sub-milestone introduces `cmd/tekhton/main.go` (plain `main`, no Cobra) and the `Makefile` that wires `-ldflags -X` to inject the contents of repo-root `VERSION` into the `version.Version` symbol.

Files to create:
- `cmd/tekhton/main.go`
- `Makefile`

Acceptance criteria:
- `cmd/tekhton/main.go` is a plain `package main` with a `main()` that prints the value of `version.Version` (followed by a single newline) and exits 0. No Cobra, no flag parsing.
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton` (bare invocation, no args) prints the trimmed contents of repo-root `VERSION` and exits 0.
- Direct `go build ./cmd/tekhton` (without `make`, no ldflags) produces a binary whose output is the literal `dev` sentinel.
- `make test` runs `go test ./...` and exits 0 (Go's "no tests to run" / "no test files" output is acceptable).
- `make clean` removes the `bin/` directory.
- Makefile sets `CGO_ENABLED=0` for the `build` target.
- Makefile uses `$(shell cat VERSION | tr -d '[:space:]')` (or equivalent whitespace-trimming form) in the `-ldflags -X` expression so trailing newlines in `VERSION` do not leak into the printed version.
- Makefile contains `build`, `test`, and `clean` targets only — no `build-all` target yet.
- No `go.sum` is created (the only import is the local `internal/version` package; no third-party deps).
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Version injection uses `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=..."`, NOT `//go:embed` — embed cannot traverse out of `cmd/tekhton/` to reach repo-root `VERSION`.
- Trim trailing whitespace both in the Makefile (`tr -d '[:space:]'`) AND defensively at print time if practical; a stray newline in `VERSION` breaks the bare-invocation acceptance check.
- Keep `cmd/tekhton/main.go` dependency-free outside of `fmt` and the local `internal/version` import to guarantee zero `go.sum` churn.
- The `make build` target must depend on `bin/` existing (or create it) — do not assume the directory is present on a clean checkout.
- `make clean` should be safe to run when `bin/` does not exist (use `rm -rf bin/` not `rmdir`).

Seeds Forward:
- Milestone 1.1.2 replaces this plain `main` with a Cobra root command, introduces the first third-party dependency (Cobra), and adds `go.sum`, `.gitignore`, and `--version` / `--help` semantics on top of the ldflags injection path established here.
- Milestone 1.2 extends this Makefile with a `build-all` cross-compile target and depends on the `CGO_ENABLED=0` convention set here.
