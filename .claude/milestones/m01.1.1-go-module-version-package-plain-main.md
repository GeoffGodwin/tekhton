#### Milestone 1.1.1: Go Module + Version Package + Plain Main

Stand up the Go module skeleton with a version package and a minimal `main.go` that prints the version. No Cobra dependency yet — this sub-milestone establishes the module, the `-ldflags "-X"` injection path, and the Makefile so that 1.1.2 can layer Cobra on top of a known-good binary.

Files to create:
- `go.mod`
- `internal/version/version.go`
- `cmd/tekhton/main.go` (plain `main` that prints version and exits 0)
- `Makefile` (with `build`, `test`, `clean` targets — no `build-all`)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23` (pinned exactly).
- `internal/version/version.go` exposes a `Version` package variable defaulting to the `dev` sentinel.
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton` (bare invocation) prints the trimmed contents of repo-root `VERSION` and exits 0.
- Direct `go build ./cmd/tekhton` (without make) produces a binary whose output is the `dev` sentinel.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes `bin/`.
- Makefile sets `CGO_ENABLED=0` for build.
- No `go.sum` is required yet (no third-party deps).
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Version comes from `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(cat VERSION)"`, NOT `//go:embed` (embed cannot traverse out of source directory).
- Trim trailing whitespace from the `VERSION` file contents in the ldflags expression (`$(shell cat VERSION | tr -d '[:space:]')`) and/or at print time.
- Pin `go 1.23` exactly in `go.mod`; drift causes CI flake later.
- Keep `cmd/tekhton/main.go` dependency-free so this sub-milestone produces zero `go.sum` churn.

Seeds Forward:
- Milestone 1.1.2 replaces the plain `main` with a Cobra root command and adds `go.sum`, `.gitignore`, and the `--version`/`--help` semantics.
- Milestone 1.2 depends on the Makefile structure to add `build-all` cross-compile target.
