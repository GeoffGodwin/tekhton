#### Milestone 1.1.2: Cobra Root Command & Version Injection

Replace the stub `main.go` with a Cobra root command, add the `internal/version` package, and wire `-ldflags "-X"` injection in the Makefile so `bin/tekhton --version` prints the trimmed contents of the repo-root `VERSION` file. This sub-milestone delivers the user-visible behavior promised by Milestone 1.1.

Files to create:
- `internal/version/version.go` (exports a `Version` variable defaulting to the `dev` sentinel)

Files to modify:
- `cmd/tekhton/main.go` (replace stub with Cobra root command implementing `--version`, `--help`, and non-zero exit on bare invocation)
- `Makefile` (extend `build` target with `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION | tr -d '[:space:]')"` or equivalent)
- `go.sum` (will populate when Cobra is added via `go mod tidy`)

Acceptance criteria:
- `bin/tekhton --version` prints the trimmed contents of the repo-root `VERSION` file (no trailing whitespace).
- `bin/tekhton --help` produces standard Cobra output.
- `bin/tekhton` invoked bare exits non-zero and shows help.
- Direct `go build ./cmd/tekhton` (without make) produces a binary whose `--version` prints `dev` (the sentinel — confirms ldflags injection is the version source, not embedded data).
- `make build` still produces `bin/tekhton` with CGO disabled.
- `make test` still exits 0.
- `internal/version/version.go` exports `Version = "dev"` as the default.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Version comes from `-ldflags "-X"` injection, NOT `//go:embed` (embed cannot traverse out of source directory to reach repo-root `VERSION`).
- Trim trailing whitespace from the `VERSION` file contents at print time (or at injection time via shell), not just newlines.
- The `dev` sentinel must be the literal string `dev` so the direct-`go build` acceptance check is unambiguous.
- Keep CGO disabled in the extended Makefile — don't regress the static-binary promise from 1.1.1.
- `go mod tidy` after adding Cobra is what populates `go.sum`; commit the result.

Seeds Forward:
- Milestone 1.2 depends on the now-complete Makefile structure to add `build-all` cross-compile target with the same ldflags injection.
- Milestone 1.3 depends on `bin/tekhton --version` working for the self-host assertion.
