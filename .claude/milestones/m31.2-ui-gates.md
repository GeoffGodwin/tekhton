## Design

### Sequencing note

m31.2 lands the parent-arc VERSION bump (`4.31.0`). The pattern matches m27's split — sub-milestones do not individually bump VERSION; the parent-arc bump fires on the close of the last child. Failing to bump VERSION on m31.2 close leaves the manifest reading m31 as done with no corresponding tag.

The Go `UIPhase` swap into `internal/gates/build.go` is the *only* runtime-behavioral change in m31.2. Everything else is byte-equivalent or a deletion. Run the m31.1 parity gate (`tests/test_gates_parity.sh`) before AND after the swap to confirm no regression in the build/completion gates from the wiring change.

### Goal 1 — `internal/gates/ui_helpers.go` — pure helpers

Port the six helper functions from `lib/gates_ui_helpers.sh`:

```go
package gates

// Framework is the detected UI test framework. Mirrors _ui_detect_framework.
type Framework string

const (
    FrameworkPlaywright Framework = "playwright"
    FrameworkNone       Framework = "none"
)

// DetectFramework reads env + filesystem to infer the UI framework.
// Priority order matches lib/gates_ui_helpers.sh:_ui_detect_framework:
//   0. TEKHTON_UI_GATE_FORCE_NONINTERACTIVE=1 → playwright (M130)
//   1. UI_FRAMEWORK env → if "playwright", return playwright
//   2. UI_TEST_CMD word-boundary regex → playwright
//   3. playwright.config.{ts,js,mjs,cjs} in PROJECT_DIR → playwright
//   4. otherwise → none
func DetectFramework(env *proto.StageEnvV1, projectDir string) Framework { ... }

// DeterministicEnvList returns the KEY=VALUE pairs to inject into the
// UI_TEST_CMD subprocess env. M131: PREFLIGHT_UI_INTERACTIVE_CONFIG_DETECTED
// escalates to hardened on the FIRST run, not just retry.
func DeterministicEnvList(env *proto.StageEnvV1, fw Framework, hardened bool) []string { ... }

// TimeoutSignature classifies the gate timeout flavor for M126 routing.
// Returns one of: "interactive_report", "generic_timeout", "none".
func TimeoutSignature(exitCode int, output string) string { ... }

// HardenedTimeout computes the hardened-rerun timeout. Clamped to [1, base].
func HardenedTimeout(base time.Duration, factor float64) time.Duration { ... }

// WriteGateDiagnosis appends a `## UI Gate Diagnosis` block to
// UI_TEST_ERRORS_FILE and BUILD_ERRORS_FILE. Caller writes raw output first.
func WriteGateDiagnosis(w ErrorsWriter, signature, normalApplied, hardenedApplied, hardenedAttempted string) error { ... }
```

Each helper is a pure function (no side effects beyond `WriteGateDiagnosis`, which writes through the shared `ErrorsWriter` interface). Unit tests in `ui_helpers_test.go` table-drive every branch and assert byte-equality against the bash output for the diagnosis block.

### Goal 2 — `internal/gates/ui.go` — `UIPhase` implementation

Port `_run_ui_test_phase`. Five behavioral branches preserved:

```go
type UIPhase struct {
    Env        *proto.StageEnvV1
    Errors     ErrorsWriter
    Remediator Remediator
    Clock      func() time.Time
    Exec       Executor  // wraps exec.CommandContext + env injection
}

func (p *UIPhase) Name() string { return "ui_test" }

func (p *UIPhase) Run(ctx context.Context, in *PhaseInput) PhaseResult {
    if p.Env.UITestCmd == "" || !p.uiValidationEnabled() {
        return PhaseResult{Status: Skip}
    }
    if !p.commandAvailable(p.Env.UITestCmd) {
        return PhaseResult{Status: Skip, Warn: "UI_TEST_CMD command not found"}
    }

    // --- Run #1: normal-run deterministic env ---
    out, exit := p.runCmd(ctx, false, p.Env.UITestTimeout, "Running UI tests")
    if exit == 0 { return PhaseResult{Status: Pass} }

    signature := TimeoutSignature(exit, out)
    hardenedAttempted := false

    if signature == "interactive_report" {
        // M126: skip M54 remediation and generic retry; hardened rerun only.
        if p.envRetryEnabled() {
            hardenedAttempted = true
            t := HardenedTimeout(p.Env.UITestTimeout, p.envRetryFactor())
            out, exit = p.runCmd(ctx, true, t, "Hardened UI test rerun")
            if exit == 0 { return PhaseResult{Status: Pass} }
        }
    } else {
        // M54 registry-based remediation
        if p.Remediator.TryRemediate(out, "build_gate_ui_test") {
            out, exit = p.runCmd(ctx, false, p.Env.UITestTimeout, "Re-running UI tests")
        }
        // Generic flakiness retry
        if exit != 0 {
            out, exit = p.runCmd(ctx, false, p.Env.UITestTimeout, "Retrying UI tests")
        }
    }

    if exit == 0 { return PhaseResult{Status: Pass} }

    // --- Failure path: write UI_TEST_ERRORS_FILE + append BUILD_ERRORS.md ---
    p.writeFailure(in.StageLabel, out, exit)
    WriteGateDiagnosis(p.Errors, signature, "yes (normal)",
        boolTag(hardenedAttempted, "yes"), boolTag(hardenedAttempted, "yes"))
    return PhaseResult{Status: Fail, Err: ErrUITestFailed}
}
```

Byte-identity points:

| Bash | Go |
|------|-----|
| `printf '%s\n' "$_ui_output" > "$BUILD_RAW_ERRORS_FILE"` (line 129) | `os.WriteFile(rawPath, []byte(output + "\n"), 0o644)` — TRUNCATE mode |
| `cat > "$UI_TEST_ERRORS_FILE" << UIEOF ... UIEOF` (line 131) | `fmt.Fprintf(w, "# UI Test Errors — %s\n## Stage\n%s\n...", clock(), stageLabel)` |
| `tail -100` on output (line 144) | `output[max(0, len(lines)-100):]` joined with newlines |
| `echo "## UI Test Failures"` appended (line 159) | `fmt.Fprintf(f, "## UI Test Failures\nCommand: `%s`\nExit code: %d\n\n```\n%s\n```\n", cmd, exit, tailedOutput)` |

The `_ui_run_cmd` env-injection-at-the-env(1)-boundary pattern (`gates_ui.sh:25-31`) becomes Go's `exec.Cmd.Env = append(os.Environ(), DeterministicEnvList(...)...)` — same isolation guarantee (env stays scoped to the subprocess), same M126 deterministic-env semantics.

### Goal 4 — `tekhton gate ui` Cobra subcommand body

m31.1 shipped `gate ui` as a stub returning `errors.New("gate ui: implemented in m31.2")`. m31.2 fills the body:

```go
var gateUICmd = &cobra.Command{
    Use:   "ui",
    Short: "Run the UI test gate (UI_TEST_CMD with M126 hardened-rerun semantics)",
    Hidden: true,
    RunE: runGateUI,
}

func runGateUI(cmd *cobra.Command, _ []string) error {
    env, err := loadStageEnv()
    if err != nil { return err }
    p := &gates.UIPhase{Env: env, ...}
    result := p.Run(cmd.Context(), &gates.PhaseInput{
        StageLabel: gateUIStageLabel,
        Remaining:  time.Duration(env.UITestTimeout) * time.Second,
    })
    if result.Status == gates.Fail { return result.Err }
    return nil
}
```

Exit code mapping: 0 on Pass/Skip, 1 on Fail. Matches the bash gate's exit semantics.

## Watch For

- **UI gates fire only when `UI_TEST_CMD` is set.** Most milestones don't exercise this code path. Verify m31.2 in dogfood against a fixture project that DOES set it (any Playwright-based fixture under `tests/testdata/gates/ui_*`); otherwise the gate's body never runs and parity is implicit, not asserted.
- **The M126 hardened-rerun branch skips both M54 remediation AND the generic retry.** `gates_ui.sh:84-102` — when signature is `interactive_report`, *only* the hardened rerun fires. A regression that runs both branches (interactive + remediation, or interactive + generic-retry) silently doubles the gate cost on every Playwright timeout and surfaces as flaky CI behavior rather than a hard failure.
- **`_normalize_ui_gate_env`'s stdout/stderr discipline.** `gates_ui_helpers.sh:90-99` — the function's stdout is consumed by `mapfile` in `_ui_run_cmd`; diagnostic output (`log_verbose`) is explicitly redirected to stderr. The Go port preserves this — `DeterministicEnvList` returns `[]string` (no logging side effect); diagnostic output goes through the logger interface, not the return value.
- **M131 escalation: `PREFLIGHT_UI_INTERACTIVE_CONFIG_DETECTED=1` forces hardened on the FIRST run.** `gates_ui_helpers.sh:65-68` — m22's UI config audit sets this env var when a known-bad reporter config is detected. The Go port's `DeterministicEnvList` checks this BEFORE the `hardened` flag; a project with a known-bad config never burns a `UI_TEST_TIMEOUT` on the first run. Regressing this is a m22 ↔ m31.2 cross-arc bug; test it.
- **The bash `env "${_env_list[@]}" timeout "$_t" bash -c "${UI_TEST_CMD:-}"` form has subtle semantics.** `env` injects the env list into the subprocess; `timeout` wraps it; `bash -c` runs the command. The Go port collapses this to `exec.CommandContext(ctx, "bash", "-c", uiTestCmd)` with `cmd.Env = append(os.Environ(), envList...)` and `ctx` carrying a `WithTimeout`. The functional behavior is identical, but the subprocess tree is one level shallower (no intermediate `env` / `timeout` processes). If any downstream test inspects the process tree (none currently do, but check), this changes shape.
- **`_ui_hardened_timeout`'s float-factor math.** `gates_ui_helpers.sh:125-141` uses `awk` for the float-to-int conversion and clamps to `[1, base]`. The Go port uses `int(math.Round(float64(base) * factor))` with the same clamping. Edge cases: `factor=0` → clamp to 1 (NOT zero — timeout 0 means "no timeout" to the `timeout` utility, which is wrong). `factor=2.0` (greater than 1) → clamp to base. Cover both edges in `TestHardenedTimeout_Clamping`.
- **UI_VALIDATION_ENABLED defaults to true.** `gates_ui.sh:45` — `[[ -n "${UI_TEST_CMD:-}" ]] && [[ "${UI_VALIDATION_ENABLED:-true}" == "true" ]] || return 0`. The Go port preserves the default — `env.UIValidationEnabled` is true unless the user explicitly sets `false`. This matters because the StageEnvV1 struct's zero value is `false`; default to `true` at parse time, not at struct-init time.
- **Don't regress the m31.1 build/completion parity.** Run `tests/test_gates_parity.sh` (m31.1's harness) before AND after the UIPhase swap. The swap is the only build-gate code change in m31.2; a regression there means the `Phase` interface contract changed under m31.1's feet.

## Seeds Forward

- **m32 (Milestone DAG runtime port):** All five `lib/gates*.sh` files are gone. The DAG runtime calls `run_build_gate` through the shim today; m32 can call `gates.BuildGate.Run` directly in-process. The shim function in `tekhton-legacy.sh` stays for the m32→m33 transition window, then deletes in m33.
- **m33 (Stages port):** Retires the bash `stages/*.sh` files. The eight `run_build_gate` call sites and the one `run_completion_gate` call site go away; the `tekhton gate <subcommand>` CLI surface goes from "internal-shim entry point" to "external-dogfood-only entry point" and can switch to Hidden=false visibility if dogfood scripts want to call it directly.
- **Errors writer interface:** Now shared between m31.1's build/completion gates and m31.2's UI gate. Future M54 auto-remediation work (the `Remediator` interface) plugs into the same shape — a m31.2 UI failure followed by remediation followed by re-run all funnel through one `ErrorsWriter` per gate invocation, and the m17 classifier reads byte-identical output.
- **Framework adapter generalization:** `DetectFramework` returns `playwright | none` today (M126 only branches on playwright). The Go type signature accommodates future Cypress / Vitest / Jest values without API churn — m57's adapter framework (referenced in `gates_ui.sh:86`) plugs in as additional `Framework` constants without changing call sites.
- **Parity-gate harness reuse:** `tests/test_gates_ui_parity.sh` is the fifth (after m21 finalize, m22 preflight, m31.1 build/completion, and any m23-m25 parity gates) parity harness using the `tests/lib/parity.sh` shared driver. If the driver hasn't been extracted by m31.2 land, do it as part of this milestone — five copies of the diff/normalize/compare scaffolding is the right point to deduplicate.
