#### Milestone 1.1.1: Go Module + Version Package + Build Plumbing

Stand up the Go module, version package with ldflags injection, and a minimal `main.go` that prints the injected version. No Cobra yet — just enough to prove the build pipeline and version wiring work end-to-end.

Files to create:
- `go.mod`
- `internal/version/version.go`
- `cmd/tekhton/main.go` (minimal — just `fmt.Println(version.Version)`)
- `Makefile` (with `build`, `test`, `clean` targets; CGO disabled; ldflags injection)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23` pinned exactly.
- `internal/version/version.go` exports a `Version` string initialized to the `dev` sentinel.
- `make build` on a clean checkout produces `bin/tekhton` with `CGO_ENABLED=0`.
- `bin/tekhton` (no args) prints the trimmed contents of repo-root `VERSION`.
- Direct `go build ./cmd/tekhton` (without make) produces a binary whose `Version` is still `dev`.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes `bin/`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- No `go.sum` yet (no external deps in this sub-milestone — Cobra arrives in 1.1.2).

Watch For:
- Version comes from `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(cat VERSION)"`, NOT `//go:embed` (embed cannot traverse out of source directory).
- Trim trailing whitespace from `VERSION` file contents when constructing the ldflags value (use `$(shell cat VERSION | tr -d '[:space:]')` or equivalent).
- CGO must stay disabled (`CGO_ENABLED=0` exported in the build target) — required for the static-binary promise.
- Pin `go 1.23` exactly in `go.mod`; drift causes CI flake later.
- Keep `main.go` deliberately minimal so 1.1.2 can replace it cleanly with Cobra.

Seeds Forward:
- Milestone 1.1.2 replaces `cmd/tekhton/main.go` with a Cobra root command and adds `go.sum` once the Cobra dependency lands.
- Milestone 1.1.2 reuses the same `Makefile` ldflags structure unchanged.
- Milestone 1.2 depends on the `Makefile` structure to add the `build-all` cross-compile target.
- Milestone 1.3 depends on `bin/tekhton --version` working (delivered in 1.1.2) for the self-host assertion.
