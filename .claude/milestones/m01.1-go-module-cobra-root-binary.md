#### Milestone 1.1: Go Module + Cobra Root Binary

Bootstrap the Go module in-repo and stand up a Cobra root command that prints `--version` from `internal/version/version.go`, with the version string injected at link time from the repo-root `VERSION` file via `-ldflags "-X"`. This sub-milestone delivers a buildable Go binary on the local host only — no cross-compilation, no CI, no self-host wiring yet. Module path is `github.com/geoffgodwin/tekhton`, pinned to `go 1.23`. CGO disabled. Cobra is the only third-party dep. The Makefile gets `build`, `test`, and `clean` targets sufficient to drive local development; cross-compile and CI land in 1.2.

Files to create:
- `go.mod`
- `go.sum`
- `cmd/tekhton/main.go`
- `internal/version/version.go`
- `Makefile` (with `build`, `test`, `clean` targets only)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`.
- Direct `go build ./cmd/tekhton` (bypassing make) leaves `Version` at the `dev` sentinel — confirming ldflags injection is the source of truth.
- `bin/tekhton --help` produces standard Cobra output; any unknown invocation prints help and exits non-zero.
- `make test` exits 0 (no tests yet is acceptable).
- `go vet ./...` is clean.
- `.gitignore` excludes `bin/` and `*.test`; no `bin/` artifact appears in `git status` after `make build`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- `bash tests/run_tests.sh` produces identical output before and after this sub-milestone.

Watch For:
- `//go:embed ../../VERSION` is invalid Go (embed paths cannot traverse parents). Use `-ldflags "-X"` only.
- Pin `go 1.23` in `go.mod` to avoid local/CI drift later.
- CGO must stay off — do not pull in any cgo-dependent transitive dep.
- Trim trailing whitespace on the version string at print time.
- Do not add subcommands here; the root is a stub for future wedges.

Seeds Forward:
- Milestone 1.2 depends on the `Makefile` skeleton from this sub-milestone to add `build-all` and the CI workflow targeting it.
- Milestone 1.3 depends on `make build` producing `bin/tekhton` so the self-host check can prepend `bin/` to `$PATH`.
- Future m02+ wedges hang subcommands off the Cobra root established here.
