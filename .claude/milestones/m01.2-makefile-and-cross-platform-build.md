#### Milestone 1.2: Makefile and Cross-Platform Build

Add the Makefile exposing `build`, `test`, `build-all`, and `clean` targets. `build-all` cross-compiles to `linux/amd64`, `linux/arm64`, `darwin/amd64`, `darwin/arm64`, `windows/amd64` with CGO disabled, emitting `bin/tekhton-<os>-<arch>[.exe]`. The local `build` target uses `-trimpath -ldflags="-s -w"` and injects the version string from repo-root `VERSION`. Documentation lands in `docs/go-build.md` (one page: prerequisite install, `make` targets, cross-compile output layout, CI artifact location).

Files to create:
- `Makefile`
- `docs/go-build.md`

Acceptance criteria:
- `make build` on a clean checkout produces `bin/tekhton`; `bin/tekhton --version` prints trimmed `VERSION`.
- `make build-all` produces all five expected binaries; `file bin/tekhton-*` shows the correct OS/arch shape for each.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes `bin/`.
- All cross-compile targets succeed with `CGO_ENABLED=0`.
- `docs/go-build.md` exists and covers install prereqs, `make` targets, cross-compile layout, CI artifact location.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- `darwin/*` only cross-compiles cleanly with CGO off — verify on Linux before relying on CI.
- Release builds must go through `make build`; direct `go build` skips ldflags and produces a `dev`-tagged binary.
- Keep `docs/go-build.md` to ~80 lines — onboarding doc, not a manual.

Seeds Forward:
- Milestone 1.3 depends on `make build` and `make build-all` for the CI workflow and self-host harness.
