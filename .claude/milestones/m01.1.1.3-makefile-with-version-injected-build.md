#### Milestone 1.1.1.3: Makefile with VERSION-injected Build

Add the project `Makefile` with `build`, `test`, and `clean` targets. The `build` target injects the trimmed `VERSION` file contents into `version.Version` via `-ldflags "-X"` and writes the binary to `bin/tekhton`. `CGO_ENABLED=0` is set for the build.

Files to create:
- `Makefile`

Acceptance criteria:
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton` (bare invocation) prints the trimmed contents of repo-root `VERSION` (whitespace stripped) and exits 0.
- A direct `go build ./cmd/tekhton` (no make) still produces a binary whose output is the `dev` sentinel — proving the ldflags override is the only source of the injected value.
- `make test` runs `go test ./...` and exits 0 (Go's "no test files" output is acceptable).
- `make clean` removes the `bin/` directory; running `make clean` twice in a row exits 0 both times.
- Makefile sets `CGO_ENABLED=0` for the `build` target (verifiable via `make -n build`).
- No `build-all` target is defined yet (that is milestone 1.2's responsibility).
- No `go.sum` file is produced by `make build`.

Watch For:
- Use `$(shell cat VERSION | tr -d '[:space:]')` (or equivalent) to strip trailing newlines — an untrimmed VERSION produces a binary that prints `1.0.0\n\n`, failing exact-match assertions later.
- The ldflags target path must be `github.com/geoffgodwin/tekhton/internal/version.Version` — a typo here silently leaves `Version` at `dev` and the build still "succeeds," so test by comparing `bin/tekhton` output against `cat VERSION`.
- `make clean` must use `rm -rf bin` (not `rm -r bin`) so the second invocation does not error on a missing directory.
- Do NOT use `//go:embed` of `VERSION` as a shortcut — `embed` cannot traverse out of the source directory (`cmd/tekhton/` cannot embed repo-root files), and this is the trap called out in the parent milestone.
- Set `CGO_ENABLED=0` as a target-scoped or recipe-line export, not as a top-level `export` that bleeds into `make test` if it might interfere.

Seeds Forward:
- Milestone 1.1.2 layers Cobra onto the binary produced here; the `--version` flag will read the same `version.Version` symbol this Makefile injects.
- Milestone 1.2 adds a `build-all` cross-compile target that reuses the same ldflags expression defined here — keep the ldflags string in a Makefile variable (e.g. `LDFLAGS`) to enable that reuse without duplication.
