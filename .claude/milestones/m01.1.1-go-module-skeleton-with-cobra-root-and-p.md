#### Milestone 1.1.1: Go Module Skeleton with Cobra Root and Placeholder Version

Stand up the Go module, Cobra root command, and Makefile such that `bin/tekhton` builds and runs, with a hardcoded `dev` version string. This sub-milestone produces a working CLI binary without ldflags injection — the version package exists but exports only the `dev` sentinel.

Files to create:
- `go.mod`
- `go.sum`
- `cmd/tekhton/main.go`
- `internal/version/version.go` (declares `var Version = "dev"`, exposes `Get()` helper)
- `Makefile` (with `build`, `test`, `clean` targets; `build` uses plain `go build` — no ldflags yet)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23` pinned exactly.
- `make build` on a clean checkout produces `bin/tekhton` with `CGO_ENABLED=0`.
- `bin/tekhton --version` prints `dev`.
- `bin/tekhton --help` produces standard Cobra output; bare invocation exits non-zero with help.
- `make test` exits 0 (Go's "no tests" output is acceptable).
- `make clean` removes `bin/`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- `Version` must be a `var` (not `const`), so 1.1.2 can override it via `-ldflags "-X"`.
- CGO_ENABLED=0 must be set in the Makefile build target, not just expected from the environment.
- Cobra root command should use `cobra.Command{Use: "tekhton", Version: version.Get()}` so `--version` is wired through Cobra's built-in flag.

Seeds Forward:
- Milestone 1.1.2 will modify the Makefile `build` target to add `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION | tr -d '[:space:]')"`.
- Milestone 1.1.2 depends on `Version` being a package-level `var` (not `const`).
- Milestone 1.2 depends on the Makefile structure to add `build-all` cross-compile target.
