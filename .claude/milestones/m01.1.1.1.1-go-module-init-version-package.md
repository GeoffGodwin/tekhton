#### Milestone 1.1.1.1.1: Go Module Init + Version Package

Initialize the Go module and create the `internal/version` package with an overrideable `Version` variable. This sub-milestone establishes the module identity and version symbol that the main binary (next sub-milestone) and the Makefile ldflags injection (1.1.1.2) both depend on.

Files to create:
- `go.mod`
- `internal/version/version.go`

Acceptance criteria:
- `go.mod` declares module `github.com/geoffgodwin/tekhton` with `go 1.23` (pinned exactly, not `1.23.X` or `1.24`).
- `internal/version/version.go` declares `package version` and exposes a package-level `Version` string variable (declared with `var`, not `const`) defaulting to the literal string `dev`.
- `go build ./internal/version` succeeds with no output and no errors.
- `go vet ./internal/version` succeeds.
- No `go.sum` file is created (the version package has no third-party imports).
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.
- No file under `cmd/` is created in this sub-milestone.

Watch For:
- `Version` MUST be a `var`, not a `const`. A `const` declaration cannot be overridden via `-ldflags "-X"` in 1.1.1.2 and the failure mode is silent (ldflags is ignored without error).
- Pin `go 1.23` exactly — do not let `go mod init` or any tool drift the directive to `1.23.X` or `1.24`. If `go mod init` writes a patch version, edit it back to bare `1.23`.
- Keep `internal/version/version.go` import-free. Even a `fmt` import here is unnecessary and risks accidentally importing third-party code that would force a `go.sum`.
- The default sentinel string must be exactly `dev` (lowercase, no whitespace, no quotes around it). Downstream tests in later milestones compare against this exact byte sequence.

Seeds Forward:
- Milestone 1.1.1.1.2 imports `github.com/geoffgodwin/tekhton/internal/version` from `cmd/tekhton/main.go` — the package path and `Version` symbol established here are the exact targets.
- Milestone 1.1.1.2 injects via `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=..."` — the fully qualified symbol path must remain stable.
