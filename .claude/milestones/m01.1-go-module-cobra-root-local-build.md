#### Milestone 1.1: Go Module + Cobra Root + Local Build

Bootstrap the Go module at the repo root and stand up the Cobra root command with `--version` support. Wire up a minimal Makefile so `make build` produces a working binary locally. This sub-milestone is purely additive Go code plus a build entry point — no CI, no cross-compile, no self-host harness yet.

Files to create:
- `go.mod` (module path `github.com/geoffgodwin/tekhton`, `go 1.23`)
- `go.sum`
- `cmd/tekhton/main.go` (Cobra root, no subcommands, `--version` flag)
- `internal/version/version.go` (`Version = "dev"` sentinel, populated via ldflags)
- `Makefile` (targets: `build`, `test`, `clean` only)

Files to modify:
- `.gitignore` (add `bin/` and `*.test`)

Acceptance criteria:
- `go.mod` declares module path `github.com/geoffgodwin/tekhton` and pins `go 1.23`.
- `make build` on a clean checkout produces `bin/tekhton`.
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`.
- `bin/tekhton` with no args prints help and exits non-zero.
- `make test` exits 0 (Go's "no tests" output acceptable).
- `go vet ./...` clean.
- `.gitignore` excludes `bin/` and `*.test`; `git status` is clean after `make build`.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Version injection must use `-ldflags "-X"` (not `//go:embed ../../VERSION` — embed cannot traverse out of the source file's directory).
- Direct `go build` without make leaves `Version` at the `dev` sentinel — only `make build` produces a release-stamped binary.
- Keep `cobra` as the sole third-party dep; resist pulling extras at this stage.
- CGO must stay disabled by default to preserve the static-binary promise downstream.

Seeds Forward:
- Milestone 1.2 depends on a working `make build` to extend the Makefile with cross-compile targets.
- Milestone 1.3 depends on `bin/tekhton --version` producing correct output for the self-host check's version assertion.
