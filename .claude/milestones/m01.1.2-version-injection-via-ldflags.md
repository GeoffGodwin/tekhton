#### Milestone 1.1.2: Version Injection via ldflags

Wire the `--version` flag into the Cobra root command using `-ldflags "-X"` injection from the repo-root `VERSION` file. This sub-milestone completes the bootstrap so the binary reports its trimmed version string.

Files to create:
- `internal/version/version.go` (exports `Version` variable defaulting to `dev` sentinel)

Files to modify:
- `cmd/tekhton/main.go` (wire `--version` flag that prints `internal/version.Version`, trimmed)
- `Makefile` (extend `build` target with `-ldflags "-X github.com/geoffgodwin/tekhton/internal/version.Version=$(shell cat VERSION)"`)

Acceptance criteria:
- `bin/tekhton --version` prints the trimmed contents of repo-root `VERSION`.
- Direct `go build ./cmd/tekhton` (without make) produces a binary whose `--version` prints `dev`.
- `make build` still succeeds and `bin/tekhton --help` still works.
- `internal/version/version.go` exposes an exported `Version` string variable initialized to `"dev"`.
- Trailing whitespace (including newline) is trimmed from the version string at print time.
- No file under `lib/`, `stages/`, `prompts/`, or `tools/` is modified.

Watch For:
- Version comes from `-ldflags "-X"` injection, NOT `//go:embed` (embed cannot traverse out of source directory to reach repo-root `VERSION`).
- Trim with `strings.TrimSpace` at print time, not at injection time — ldflags injection preserves the file's trailing newline.
- The ldflags path must match the package import path exactly: `github.com/geoffgodwin/tekhton/internal/version.Version`.
- `$(shell cat VERSION)` in the Makefile must run at make-invocation time, not Go build time.

Seeds Forward:
- Milestone 1.2 depends on the Makefile ldflags structure to extend into a `build-all` cross-compile target.
- Milestone 1.3 depends on `bin/tekhton --version` working for the self-host assertion.
